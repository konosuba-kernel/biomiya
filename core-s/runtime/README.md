# B2 目标运行库

这些 `.vt` 由宿主种子编译成 RV64 机器码；文件读取、清单解析、扫描和字节输出均在目标程序里执行。`linux.s0` 只搬运 C ABI 参数、执行系统调用和读取初始栈，不代替扫描器或文件算法。

`linux.vt` 是 Linux 适配边界，系统调用编号采用 [Linux v6.12 asm-generic ABI](https://github.com/torvalds/linux/blob/v6.12/include/uapi/asm-generic/unistd.h)。`_start` 保存初始 sp 到 x27，普通函数及 `.s0` 均保持该寄存器。负 errno 以 usize 原始位模式识别，不要求语言已有 isize。

- `bytes.vt`：切片比较、子视图、路径检查；视图不分配，也不延长输入存储的寿命。
- `linux.vt`：argv、文件打开／关闭、短读写循环、EINTR 重试及有界整文件读取。一次 read 最多请求 4096 字节。close 不盲目重试，以免复用后的描述符被再次关闭。
- `compiler/source.vt`／`scan.vt`：Source 游标、Token 字节范围、带位置的错误。识别 ASCII 标识符、数字词素、字符串／转义、标点、行及嵌套块注释。数字的值／类型及语法合法性留给后续解析；非 ASCII 标识符报告 code=2。注释和字符串允许 UTF-8 字节，不代表已自写完整 Unicode 词法器。
- `compiler/manifest.vt`：实际解析行清单。切片引用清单缓冲；`entry` 和 `assembly` 会校验出现次数／路径，但复制程序只读取 source 列表。
- `app/copy.vt`：读取清单、逐源扫描并拼接原始字节。O_EXCL 创建输出，拒绝已有文件；读取、扫描或输出失败会关闭句柄并删除本次创建的输出。

首版固定上限：清单 16 KiB，source 32 项，assembly 8 项，路径 96 字节，单源 64 KiB。清单缓冲和一个复用的源缓冲位于 BSS；无需堆分配。路径检查拒绝空白、控制字符、反斜线、绝对路径、空分量及 `.`／`..`。目标清单以 ASCII 空白分隔指令／参数，路径内也拒绝 Unicode 空白的 UTF-8 编码。两者均不构成符号链接安全沙箱。视图在 unsafe 访问期间必须保持有效。

复制程序退出码：0 成功；10 argv；11 路径；12 打开／已有输出；13 关闭；14 删除；15 读取；16 写入／零进展；17 缓冲上限；20 清单；21 扫描。扫描器库保留具体字节位置，当前命令行只返回分类退出码。输入读取无论成功或失败都会关闭描述符；关闭失败会作为失败处理，已有读取错误优先。输出关闭失败同样清理新输出。

`tests/b2_runtime.rs` 用真实 RV64 执行检查成功和失败路径。短 I/O provider 只替换系统调用边界，强制每次最多 7 字节并各注入一次 EINTR；复制仍由同一套目标源码完成。
