草案 R1a，2026-10-10。首个目标配置暂名 `rv64-teaching-v1`。本次实现约束修订去掉通用 `@section`，并明确局部具体类型可以按需建立；其余 R1 规则沿用。

本语言用于编写 konOSuba 的编译器、内核、运行支持和小型应用。它提供具体数据类型、明确求值顺序、显式存储访问和有限的结构化清理，不提供用户泛型、编译期程序或隐式资源管理。

## 1 语言边界

语言负责名字与可见性、具体类型、对象布局、基础操作合法性、求值顺序、规定的运行时检查和退出清理。

程序与平台负责分配和回收、指针有效期、对象初始化、并发同步、设备协议和硬件现场。通过编译不保证无泄漏、无悬垂、单次释放或无数据竞争。`unsafe` 表示显式承担某些操作的前置条件，不关闭类型、可见性、边界或算术检查。

本版不包含：用户泛型、trait、方法和重载、宏、闭包、继承、语言引用、隐式移动、析构、GC、异常展开、协程、编译期用户函数、浮点、128 位整数、packed、内联汇编、动态链接或通用分析插件接口。本文定义的语法和内建是闭合集合，不从其他语言补入 for、范围、解构、复合赋值等未列规则。

三个结果必须区别：

| 结果 | 含义 |
| --- | --- |
| 编译错误 | 违反本文可静态判断的规则，必须拒绝 |
| panic | 规定的运行时检查失败，终止当前执行环境，不返回、不展开 |
| 执行合同违反 | 如悬垂访问、非法表示或数据竞争，从违反操作起不再规定后续行为；不要求自动检测 |

实现资源耗尽和尚未实现的合法特性必须单独报告，不能伪称语言错误。不可达语句、未调用函数和未使用声明也检查；不以“最终不生成机器码”为由跳过基础检查。

## 2 源文件与词法

源文件为 UTF-8，推荐扩展名 `.vt`。不接受 BOM。LF、CRLF 和 CR 均可分隔行；空格、制表符、换行、垂直制表和换页为空白。

支持 `//` 行注释和可嵌套的 `/* ... */`。`///` 仍是行注释，工具可展示为文档。未闭合的字符串或注释拒绝。

标识符为 Unicode 15.1 的 `XID_Start XID_Continue*`，或 `_` 后接至少一个 `XID_Continue`。不做 Unicode 规范化，按标量序列区分名字。单独 `_` 仅用于模式。保留以下词及类型名字：

```text
module import pub type struct enum fn const static mut let var
if else match while loop break continue return defer unsafe extern abi as
true false null core root sizeof alignof offsetof static_assert
u8 u16 u32 u64 usize i8 i16 i32 i64 isize bool Option Result
```

`C` 只在 `abi(C)` 中有特殊含义。`Some/None/Ok/Err` 只是固定类型的变体名，不独立预导入。

整数使用十进制、`0x` 十六进制或 `0b` 二进制，可在数字之间插入 `_`，不允许连续／首尾分隔下划线。可接 `_u32` 等整数类型后缀；后缀前的 `_` 不算数值分隔符。无后缀整数没有默认类型，按第 5 节确定。

负号是单独记号。对直接的一元负整数字面量，幅度允许达到所选有符号类型的 `MAX+1`，因此 `-128_i8` 合法，`128_i8` 和 `-(128_i8)` 拒绝。

字符串用双引号包围，不跨物理行。普通字符编码为 UTF-8 字节，支持 `\0 \n \r \t \\ \" \xHH`；`\xHH` 可产生任意字节。未知转义拒绝。字符串类型为 `[]const u8`，底层字节具有静态存储期，不自动追加零。相同字节串允许共享存储。

按最长记号匹配运算符。`?` 仅在第 9 节规定的绑定语句中出现，不是通用后缀运算符。嵌套类型中的 `>>` 在类型解析上下文中作为两个 `>` 处理；表达式中的 `>>` 是右移。

## 3 模块与名字

编译输入是显式源文件列表。文件可用 `module a::b;` 声明所属模块，缺省属于根模块。同名模块的文件合并，模块路径的前缀自动形成命名容器。声明可前向引用，结果不依赖输入文件排列。没有目录自动发现、包管理或条件编译。

仅支持模块导入：`import memory::page;` 把模块以末段 `page` 引入当前模块，使用 `page::allocate()`。导入路径从根解析；不支持名字列表、别名、通配或重导出。模块间允许循环导入。

单段名字按最内层局部、外层局部、当前模块声明查找。多段路径以当前模块可见的模块／类型名字开始；`root::a::b` 从用户根开始，`core::name` 指定内建。类型路径最后必须得到类型；枚举变体必须带类型路径。没有根据期待类型省略变体所属类型的规则。

模块、类型、函数、常量、静态对象及导入在同一作用域共用名字空间，同名冲突拒绝。类型的字段和变体各有独立成员名字空间。局部同层重名拒绝，内层可遮蔽外层非保留名字；局部从初始化完成后可见。被值名字遮蔽的类型不能靠另一套名字空间自动找到，须使用限定路径。

顶层声明默认当前模块私有，`pub` 公开。父子模块不自动拥有彼此私有权限。结构字段默认私有，可逐字段 `pub`；枚举变体随类型可见。公开函数签名、公开字段、公开常量／静态对象类型、公开枚举载荷及公开别名所暴露的类型必须对外可见；私有结构字段可以使用私有类型。

构造结构必须有权访问全部字段；`offsetof` 也检查字段可见性。类型名可公开而字段私有，此时其他模块可以保存、复制和传递该值，但不能自行构造或访问私有字段。

## 4 声明与具体类型

```text
type Count = usize;
struct Pair { pub left:u32, pub right:u32 }
enum Error { Exhausted, Invalid }
fn add(a:u32, b:u32) -> u32 { return a + b; }
const CAP:usize = 64;
static mut COUNTER:u64 = 0;
```

`type` 是透明别名，不产生新身份。别名展开遇到具名结构／枚举停止；只由别名组成的环即使穿过指针也拒绝。结构和枚举按声明身份区分；不能因为字段相同而互换。`struct Node { next:*Node }` 合法，`struct Bad { next:Bad }` 拒绝。

结构可以为空，字段不得重名。枚举至少一个变体，每个变体无载荷或恰有一个具体类型载荷；多个数据组成结构后作为载荷。无显式判别值、无嵌套声明、无元组或 newtype 专用声明。

对象类型是以下闭合集合：

| 类别 | 写法 |
| --- | --- |
| 整数 | `u8/u16/u32/u64/usize` 与对应有符号类型 |
| 布尔与单位 | `bool`、`()` |
| 原始指针 | `*T`、`*const T` |
| 固定数组与切片 | `[N]T`、`[]T`、`[]const T` |
| 具名类型 | 结构、枚举及其透明别名 |
| 固定类型构造 | `Option<T>`、`Result<T,E>` |
| 非捕获函数指针 | `fn(T,...)->R`，可带 `unsafe` 和／或 `extern abi(C)` |

每个类型出现都必须具体，数组长度依第 11 节求值。`usize/isize` 与等宽的 `u64/i64` 仍是不同类型。`Option/Result` 只是两个封闭类型构造，不允许用户声明其他类型参数化构造。

`!` 仅允许作为函数／函数指针的整个结果，表示不返回；不是对象类型，不能做字段、数组元素、类型实参或指针目标。无零值函数指针；函数指针保存完整参数、结果、ABI 和调用授权信息。

函数参数及结果类型必须显式。普通递归合法，无重载、默认参数或可变参数。参数绑定不可重新赋值。`unsafe fn` 的调用需要 unsafe 块，但其函数体不会自动获得 unsafe 授权。内部函数签名中的参数个数、返回类型、unsafe 和 ABI 必须完全相同才是同一函数指针类型；无自动适配。

## 5 定型与转换

检查只有“按一个已知类型检查表达式”和“从表达式本身确定类型”。不建立未知类型变量，不从后续使用回推，不重复求解。

显式绑定、赋值右侧、函数结果、已知调用形参和已知构造字段提供期待类型。函数、字段、索引及固定内建的结果由它们自己的输入／声明决定，再与期待类型比较；期待结果不反过来修改输入。

```text
let a:u32 = 1;          // 接受：绑定给出类型
let b = add(a, 2);      // 接受：签名给出参数和结果类型
let c = 3_u32;         // 接受：后缀给出类型
let d = 3;             // 拒绝：没有默认整数类型
```

对于算术／位运算，有已知整数期待类型时按该类型检查两侧；没有时先确定左侧，再按左侧类型检查右侧。比较一律先确定左侧类型，再检查右侧，其 bool 结果不为操作数提供类型。不得为使左侧成立而查看右侧。

```text
if a == 0 { return; }           // 当 a:u32 且当前函数结果为 () 时接受
if 0 == a { return; }           // 拒绝：左侧无类型
let x:u32 = 1 + 2;             // 接受
let y = 1_u32 + 2;             // 接受
let z = 1 + 2_u32;             // 拒绝
```

一元整数操作同样接收已知整数期待类型，或从操作数确定。逻辑操作数固定按 bool 检查。`null` 仅在已知原始指针类型处合法。整数 `as T` 的目标不为源表达式提供类型，例如 `1 as u64` 拒绝，`1_u32 as u64` 接受。

整数转换保留数学值模 `2^目标位宽` 后的位，再按目标符号解释。没有隐式整数提升、整数／bool 互转、指针转换、数组转切片、函数 ABI 转换或可变视图自动变只读。透明别名展开不算转换。

## 6 值、位置与求值顺序

所有普通值统一复制。结构和数组复制逻辑成员，枚举复制标签及活动载荷；指针、函数指针、切片只复制自身描述，不复制目标。没有自动 retain、release、析构或移动后失效。复制句柄不产生一份新的释放责任。

位置包括局部／参数／静态对象、原始解引用，以及位置的字段和数组／切片下标。`p.field` 不自动解引用，须写 `(*p).field`。右值结构／数组可以读成员，但不能写入或取址。枚举载荷只能由 match 或受限错误传播取得。

`let` 位置不可写，`var` 位置可写；字段和数组元素继承基位置的可写性。`let p:*T` 不可改写 p，但允许通过 p 写目标；只读指针和只读切片不能写目标。切片 `.data/.len`、数组 `.len` 均为只读伪字段。

数组下标按 usize 检查，越界 panic。直接访问一个合法的局部数组不需 unsafe。切片下标读／写／取址均需 unsafe，因为描述符不证明目标仍存活；检查下标不能代替寿命证明。数组位置 `.len` 不读元素；切片 `.len/.data` 读取合法描述符但不访问目标。

普通求值从左到右，每个操作数仅一次。调用先求函数值，再逐个求实参；**每个实参在求值时立即形成按值快照**，之后才求下一个实参。结构按源码字段顺序求值，布局仍按声明顺序。数组元素从左到右。`&&/||` 按通常规则短路。

赋值仅是语句：`place = rhs;`。先求右侧完整值并保存，再计算左侧位置，最后写入。定位左侧失败时不写入，已有副作用不撤回。赋值覆盖旧值不隐式释放。

局部和参数存储在所属作用域完成清理后结束；临时存储在所属完整语句结束后结束。取址不延长寿命。常量没有可取地址的独立存储，静态对象和字符串字节有静态存储期。

填充和未活动枚举载荷不要求初始化；复制可搬运这些字节，不得将它们解释为已初始化字段。不可据可写指针或不同指针目标类型自动假设独占／不别名。

## 7 表达式与整数行为

表达式包括字面量、路径、括号、调用、字段、下标、构造、内建、一元／二元操作和整数转换。块、if、match、赋值、return、unsafe 都不是表达式。

```text
Pair { left:1, right:2 }
Error::Exhausted
Option::<u32>::Some(7)
Option::<u32>::None
Result::<u32,Error>::Ok(7)
Result::<u32,Error>::Err(Error::Invalid)
```

结构构造必须写全且恰写一次所有字段，无字段简写／更新。枚举构造必须带所属类型；固定 Option／Result 的类型实参全部显式。没有独立 `Some(...)`、`Ok(...)`。

数组构造 `[a,b,...]`、`[e;N]` 必须处在已知 `[M]T` 期待类型位置；元素按 T 检查，长度必须相等。重复次数是布局前常量。重复构造只求 e 一次再复制 N 份，N 为零仍求 e 一次。空构造 `[]` 仅能在零长度数组期待类型处使用。

| 操作 | 行为 |
| --- | --- |
| `+ - *` | 同型整数，数学结果超范围则 panic |
| `+% -% *%` | 同型整数，按位宽模运算 |
| `/ %` | 同型整数，向零截断；余数同被除数符号；除零以及有符号 MIN 与 -1 组合均 panic |
| 一元 `-` | 仅有符号整数，MIN 取负 panic；直接 MIN 字面量按词法特例 |
| `& \| ^ ~` | 整数逐位操作，无语言引用的一元 `&` |
| `<< >>` | 两侧同整数类型；计数小于 0 或不小于位宽则 panic；左移丢弃高位，右移按符号扩展／零扩展 |
| `< <= > >=` | 同型整数比较 |
| `== !=` | 同型整数、bool、unit、原始指针或函数指针；指针比较数值地址 |
| `! && \|\|` | 仅 bool；后两者短路 |

不支持聚合／切片相等、字符串内容比较或运算符重载。字符串比较由普通库函数实现。条件只接受 bool。

优先级从高到低：调用／字段／下标，一元，`as`，乘除余，加减（含包装操作），移位，位与，位异或，位或，序比较，相等，`&&`，`||`。二元及转换左结合，一元右结合；转换后使用后缀须括号。控制流头部最外层不接受未加括号的结构构造，避免与随后 `{` 混淆。

结果为 `!` 的调用只允许作为完整表达式语句，例如 `core::panic("bad");`；不得嵌入参数、构造、绑定或 return。它没有正常后继，但不是可以自动转换为任何值的表达式。

## 8 局部变量与语句

```text
let x:T = e;    let x = e;
var x:T = e;    var x = e;
unsafe { var slot:T; /* 原始未初始化槽 */ }
```

普通局部必须初始化。仅在词法 unsafe 块内部允许 `var name:T;`，T 必写，不隐式清零；defer 体仍禁止这种声明。声明后取址／写入可初始化槽，任何读取前都必须形成合法值，编译器不证明任意 raw 写入的初始化效果。槽的名字不能离开声明块；泄露其地址不会延长存储期。

块只包含语句，无尾表达式。支持普通表达式语句、赋值、嵌套块、unsafe 块、if／else、while、loop、match、return、break、continue 和 defer。`else if` 是 else 中嵌套 if 的固定写法。

`return e;` 按函数结果检查并先保存返回快照；`return;` 仅用于 unit 结果，等价于 `return ();`。`break;`／`continue;` 指向最近循环，无标签或带值退出。while 条件每轮重新求值；loop 无条件重复。

所有函数都不能到达正文末尾，包括返回 unit 的函数。判定使用保守的结构规则：return 和独立 `!` 调用不落下；if 两臂及穷尽 match 按任一臂可落下决定；缺 else 和 while 总可能落下；loop 只要语法上有指向它的 break 就可能落下，包括不可达 break。顺序组合中已经不能落下的前缀不会因后面语句恢复后继。

不按常量条件、循环必然终止或 defer 必然 panic 改变这一判定。所有语句仍检查名字、类型和上下文；`while true` 之后仍需显式合法退出，确实无限循环应写 loop。

## 9 浅层匹配与错误传播

match 先复制被检值一次，然后执行匹配臂。模式限于 bool 值、整数字面量、枚举变体和最后的 `_`。整数字面量从被检类型得到期待类型。

```text
match value {
    Option::<u32>::Some(n) => { use(n); },
    Option::<u32>::None => { return; },
}
```

载荷只能绑定一个名字或 `_`，可以显式写 `name:T`；省略时直接使用已声明的载荷类型。绑定是该臂内的 let。不存在递归模式、载荷常量模式、结构模式、守卫、范围或多模式合并。

bool 和枚举须列全或以 `_` 兜底；整数无论位宽都必须有最后 `_`。重复常量／变体、多个 `_`、`_` 后的臂拒绝。完整显式覆盖后的冗余 `_` 也拒绝。检查只针对顶层标签，不构造递归模式矩阵。

错误传播只允许两种绑定语句：

```text
let value:T = expression?;
var value:T = expression?;
```

这里 T 必写；expression 本身不能包含 `?`，从其自身确定类型且必须为 `Result<T,E>`。当前函数必须返回 `Result<U,E>`，E 精确相同，无错误转换。该操作求 expression 一次：Ok 复制载荷并完成绑定，Err 保存当前函数的 Err 返回值、执行退出清理并返回；失败路径不建立新绑定。

`return f()?;`、`x = f()?;`、`g(f()?);`、`let x = f()?;` 均拒绝。需要的中间结果先显式命名。绑定式传播仍可能成功，不能用它证明函数没有正常后继。无 errdefer、异常捕获或 panic 恢复。

## 10 defer 与退出

只支持 `defer { statements }`。执行到它时向当前块注册动作，不执行体内表达式。名字在注册点绑定，只能引用当时可见的绑定；值在退出执行时读取。之后出现的同名遮蔽不改变捕获对象。

自然退出、return、传播错误、break 和 continue 都执行实际退出作用域中的已注册动作，内层先于外层，同块逆注册顺序。返回值／错误值必须先形成完整快照，再执行动作；动作改动原局部不会改写返回快照。

defer 体只准普通表达式、赋值、已初始化局部、块、unsafe、if 和浅层 match。不准循环、未初始化局部、return、`?`、break、continue 或嵌套 defer；调用的普通函数可使用自己的正常控制流。若动作 panic 或调用不返回函数，本路径停止，剩余动作不执行。

条件分支内注册的动作在该分支块结束时执行，不延后到外层。循环体每轮是新的动态块。若希望跨分支持有资源，在外块登记动作并用显式 armed 状态控制。结构化语法使同一注册点在一次动态块中最多执行一次，不要求运行时可增长的清理栈。

本语言仅保证这些显式退出的清理。停机、机器复位、panic，以及平台直接销毁进程，不保证执行语言 defer；进程级资源回收由平台完成。

## 11 常量、布局与静态数据

### 11.1 常量

`const NAME:T = e;` 的 T 必写且仅限整数、bool、unit。常量表达式只包含相应字面量、常量名字、括号、上述标量的一元／二元操作和整数转换，以及布局查询。没有聚合 const、函数调用、块、局部变量、内存读取或流程语句。

常量可以前向引用；引用图成环拒绝。所有子树均检查合法性和类型，依赖收集也包括短路右侧；求值时逻辑操作仍短路。实际求值发生的算术失败变成编译错误。

### 11.2 分阶段规则

布局前常量是本身及传递引用的初始化式都不含 `sizeof/alignof/offsetof` 的 const。按完整语法依赖判定，不借助短路值绕过限制。数组长度、重复次数和 `@align` 参数只允许布局前常量表达式，并按 usize 检查；这里不能引用局部名字或任何布局后常量。

实现依次建立以下事实：

1. 收集声明与签名，解析名字和透明别名。
2. 求布局前常量及当前待布局类型的数组长度／对齐参数。
3. 计算具体类型布局，拒绝按值递归；零长度数组仍要求元素布局合法。
4. 求含布局查询的常量及断言。
5. 检查并生成静态数据和符号重定位，再检查函数体。

第 4 步结果不能反馈到第 2 步。函数中的类型出现也遵守该依赖顺序；实现可预先收集，也可在检查函数时，用已确定的布局前常量按需构造并缓存具体类型。后者不能重新解释常量、反推全局声明或执行／重复推导函数表达式，不要求在检查第一个函数前冻结整个 TypeId 表。

```text
const COUNT:usize = 8;
struct Items { data:[COUNT]u32 }
const BYTES:usize = sizeof(Items);
static_assert(BYTES == 32);
struct Bad { data:[BYTES]u8 }    // 拒绝：长度依赖布局后常量
```

`sizeof(T)/alignof(T)` 接受合法对象类型，结果 usize；`offsetof(S,field)` 仅接受具名结构的一个可见字段。可用于运行时表达式，但值是目标事实。`static_assert(e);` 仅模块级，e 必须为常量 true。

### 11.3 静态对象

`static NAME:T = initializer;` 创建只读对象；`static mut` 创建可写对象，T 和初始化器都必写。初始化器允许标量常量表达式、字符串、null、具名普通／C 函数地址、具体结构／枚举／Option／Result／数组构造，以及本编译单元静态对象的根地址。

根地址只用 `core::addr_of(NAME)` 或 `core::addr_of_mut(NAME)`；后者要求 static mut。它们不读取初始化值，不要求 unsafe。允许自取址和互取址，通过重定位处理；不允许静态子字段地址、数组元素地址、extern 地址、地址比较或地址算术。除这些取址节点外，初始化器不调用内建或普通函数，不读取其他静态值，不做聚合投影。

```text
struct Link { next:*const Link }
static HEAD:Link = Link { next:core::addr_of(HEAD) };
```

静态初始化不产生运行期构造函数。全零合法表示的初始化器可以放零初始化区；不是所有类型都有合法零值。复杂运行时表由入口显式初始化。不同静态声明有不同逻辑对象身份，不能因为值相同就合并其有身份的存储。

## 12 原始存储与 unsafe

原始指针是普通内存地址，允许为零、越界、未映射或失效。仅形成／保存这样的数值不访问内存。真正读取／写入必须满足完整范围有效、映射与权限正确、自然对齐、对象仍存活；读还要求已初始化且表示合法。

零大小类型访问不读取字节，但仍要求非空、对齐、存活的逻辑对象。不同零大小对象数值地址可相同，地址相等不证明相同身份。

普通 raw 解引用、raw 位置的字段／索引访问及取址、切片元素访问、可写 static 的读取／写入、extern static 的读取／写入，以及 unsafe 函数／C 函数调用，都要求词法 unsafe 块。仅取得具名本地／静态／extern 根对象地址不读对象，可以不使用 unsafe；外部根地址特例见第 16 节。

从未初始化结构／数组中取字段／元素地址，不要求先读取整个对象。定位表达式本身如指针值、索引和切片描述符必须合法；写入所有字段后才允许复制整个结构，填充除外。枚举只能用完整变体值初始化，不能投影非法标签的载荷。

只读局部／静态对象不能通过整数往返重建可写指针后写入。指针的 const 限制这一访问路径，不证明不存在其他可写别名。语言不采用基于目标类型的严格别名假设；合法字节存储可按满足对齐／大小／表示的类型访问，但不能借此读非法 bool、枚举或函数指针。

切片是地址和长度，无独占权与寿命参数。形成切片须满足非空对齐地址、长度乘元素大小可表示、完整存活且已初始化的元素范围和相应权限；空切片可用非空对齐哨兵或适当一过尾地址。空字符串和零长度数组的 slice_of 结果也必须使用非空对齐地址。之后每次元素访问仍需存活且同步。

内存分配、失败处理、arena、对象池、引用计数和句柄代际检查都是普通库代码。库合同不能被当成编译器已证明的性质。

## 13 有限内建

除布局查询外，内建只用完整 `core::name` 调用，不可导入为别名、重定义或取函数指针。表中的 T、I、U、P、N 是说明元变量，不是用户泛型；按已知实参或显式类型操作数选择，不进行求解。

所有普通值实参按第 6 节逐项求值并保存。位置实参只定位一次；其自身要求的 unsafe 和索引检查仍适用。

| 内建 | 类型与行为 | 授权 |
| --- | --- | --- |
| `addr_of(place)` | 由位置 T 得到 `*const T`，不读载荷 | 依位置来源 |
| `addr_of_mut(place)` | 可写位置 T 得到 `*T`，不读载荷 | 依位置来源 |
| `addr(p)` | 原始指针 P 得到 usize 地址位 | 普通 |
| `ptr::<T>(a)` | a 按 usize 检查，得到 `*T`；不建立映射或寿命 | unsafe |
| `ptr_const(p)` | `*T` 得到 `*const T` | 普通 |
| `ptr_add(p,n)` | 已知 P，n:usize；按 `n*sizeof(T)` 加地址，保留 const 性 | unsafe |
| `ptr_add_bytes(p,n)` | 已知 P，n:usize；按字节加地址，保留 const 性 | unsafe |
| `slice_from_raw_parts(p,n)` | `*const T` 与 usize 得到 `[]const T` | unsafe |
| `slice_from_raw_parts_mut(p,n)` | `*T` 与 usize 得到 `[]T` | unsafe |
| `slice_const(s)` | `[]T` 得到 `[]const T` | 普通 |
| `slice_of(place)` | 已初始化 `[N]T` 位置得到只读切片，不复制元素 | 依位置来源 |
| `slice_of_mut(place)` | 已初始化可写 `[N]T` 位置得到可写切片 | 依位置来源 |
| `copy_bytes(dst,src,n)` | `*u8,*const u8,usize`；按调用前字节快照复制，允许重叠 | unsafe |
| `fill_bytes(dst,b,n)` | `*u8,u8,usize`；初始化对应字节 | unsafe |
| `volatile_load(p)` | 已知 `*const I`，I 为整数，得到 I；一次同宽 RAM 读 | unsafe |
| `volatile_store(p,v)` | 已知 `*I`，v 按 I 检查；一次同宽 RAM 写 | unsafe |
| `panic(message)` | `[]const u8`，结果 `!`，按第 17 节终止 | 普通 |

地址乘加溢出 usize 时 panic，允许计算超出对象范围的地址，但不授予访问权。转换指针目标须显式 `core::ptr::<U>(core::addr(p))`，需要只读结果再调用 ptr_const。无函数指针和整数／数据指针之间的转换。

copy_bytes 保留字节的未初始化状态，不把无效表示变成合法值；fill_bytes 只保证字节初始化。n 为零时两者不访问内存。非零范围必须满足普通 RAM 合同，不得包含正在使用的原子存储或设备寄存器。volatile 不能替代原子或设备协议，也不要求对象始终不变。

## 14 设备与原子

本草案删除语言内建地址空间。普通指针仅用于普通 RAM；物理地址、用户地址和设备区域可由库用具名结构包装。数值重标记不建立映射、不能代替故障可恢复的用户拷贝，也不能授权绕过设备协议。与 Core S 相比，这明确失去了部分地址空间误用的静态拒绝。

设备操作固定为 `core::mmio_load_u8/u16/u32/u64(address:usize)` 和相应 `mmio_store_u8/u16/u32/u64(address:usize,value:I)`。斜杠表示八个独立名字，不是源语法。load 返回对应 I，store 返回 unit；全部 unsafe。地址须为已映射的设备虚拟地址、按访问宽度对齐，并符合设备允许的宽度、方向和状态；每次恰作一次同宽访问，不合并、拆分或消除。

`core::device_fence()->()` 为 unsafe 设备顺序操作；本目标使用保守的 `fence iorw,iorw`。MMIO 和 fence 保持源序，并作为普通内存的编译器屏障；硬件顺序只由实际 fence／平台协议给出。fence 不证明 DMA 已完成，不建立普通线程间的原子同步。

原子槽只支持独立自然对齐的 u32 或 u64 RAM：

| 内建 | 参数与结果 |
| --- | --- |
| `core::atomic_load(p)` | `*const U -> U` |
| `core::atomic_store(p,v)` | `*U,U -> ()` |
| `core::atomic_exchange(p,v)` | `*U,U -> U`，返回旧值 |
| `core::atomic_compare_exchange(p,expected,next)` | `*U,U,U -> U`，返回观察值；相等才写 next；强 CAS |
| `core::atomic_fetch_add/sub/and/or(p,v)` | 四个固定名字，`*U,U -> U`；返回旧值；add/sub 按位宽包装 |

U 由第一个已知指针实参确定，只能精确为 u32/u64。全部 unsafe，全部顺序一致（SC），没有内存序参数、独立原子 fence、窄原子、指针原子或 Atomic 包装类型。

发布前独占初始化，发布后只允许同宽原子访问；直到全部使用者静止并重新获得独占权，不能普通／volatile 访问或按聚合复制该存储。指针可复制不代表原子槽可复制。

SC 操作有一个保持各执行上下文源序及 happens-before 的全序；每次 load 观察该序中本槽最近写入，没有此前原子写时观察合法发布的初始值，RMW 的读写不可分开。SC 读有 acquire、写有 release，读到的发布与获取建立同步；源序与同步边的传递闭包确定 happens-before，不允许凭空值或循环自证的同步。不同执行上下文对普通内存的冲突访问，若至少一次为写而没有先后／互斥保证，就是数据竞争和执行合同违反。IRQ、可重入陷阱和其他 hart 都是执行上下文。

原子实现可使用 AMO 或 LR/SC 重试，不能分配或调用可能睡眠的锁；强 CAS 不得把保留集丢失作为不相等返回。不承诺 wait-free。后端须使用附录 B 固定的原子映射或证明等价的实现，不能以 volatile 替代。

## 15 布局与属性

本目标为小端 RV64，整数二元补码。布局不重排字段，不进行空指针 niche 或标签压缩。

| 类型 | 大小／对齐 |
| --- | --- |
| 各固定宽度整数 | 位宽除以 8，两者相同 |
| usize／isize、原始／函数指针 | 8／8 |
| bool | 1／1，仅 0 和 1 合法 |
| unit、空结构 | 0／1，类型 align 属性可提高 |
| 切片 | 16／8，地址偏移 0、长度偏移 8 |

结构字段按声明顺序，将当前位置向上对齐到字段对齐后放置；整体对齐为字段最大对齐与类型 align 要求的最大值，最终大小向上对齐。数组元素连续，步长 sizeof(T)，对齐 alignof(T)；零长度仍保留元素对齐。

枚举标签为 u32，按声明顺序从 0 编号；最多 `2^32` 个变体。载荷区起点按最大载荷对齐向上对齐标签末尾，区域大小为最大载荷大小；整体对齐至少为 4，尾部向上对齐。无载荷时载荷大小 0、对齐 1。Option 的 Some／None 标签为 0／1，Result 的 Ok／Err 为 0／1，使用同一规则。非法标签不能作为值读取。

仅支持以下属性，未知、重复或位置不符均拒绝：

| 属性 | 允许位置与作用 |
| --- | --- |
| `@align(N)` | 结构或本地 static；N 为布局前 usize 常量、1 到 4096 的 2 次幂；只提高对齐，不降低 |
| `@repr(C)` | 具名结构，字段限整数、bool、普通数据指针、C 函数指针、递归此类非空结构及正长度数组 |
| `@export("name")` | 有体 C ABI 函数或本地 static，指定外部符号 |

repr(C) 结构不得为空或组合 align，不支持 C union、位域、柔性数组。普通内部布局与 C 合同仍区别命名，即使部分字段布局恰好一致。大小、偏移、数组乘法或向上对齐超出 usize 表示范围时编译失败。

外部符号名只接受 ASCII `[A-Za-z_][A-Za-z0-9_]*`。用户不得导出 `_start` 或 `__biomiya_` 前缀。非 ASCII 源名字可以存在，但直接外部声明名必须符合符号规则；导出可用属性指定 ASCII 名字。不支持任意 ELF 字节名字恢复机制。

没有通用 `@section`。对象按代码、只读、可写及零初始化性质放入目标固定区域；入口、边界符号及固件布局由构建 profile 明确定义。自举尚未提出需要用户自定节和任意链接脚本的用例，不预留这项语言承诺。

## 16 外部接口与调用约定

```text
extern abi(C) fn platform_putc(byte:u8) -> ();
extern abi(C) static IMAGE_END:u8;

@export("kernel_main")
extern abi(C) fn start() -> () {
    unsafe { platform_putc(65); }
    return;
}
```

外部函数没有函数体；带体 C ABI 函数由本编译单元定义。两者及 C 函数指针的调用都必须 unsafe；是否另写 unsafe 不改变 C 调用的有效授权要求。普通与 C 函数指针不能互转。C 签名参数／结果只准整数、bool、数据指针和具有同类 C 签名的 C 函数指针；unit 仅用作 void 结果，另允许 `!` 表示 C noreturn 合同。无聚合按值、切片、可变参数。

extern static 不分配存储，可声明 mut。实际读写须符合对象布局和可写合同。仅对根符号取址时允许它是构建 profile 提供的地址边界，不要求有可读对象；取址不得生成加载。extern static 根地址不参与源静态初始化，须在运行时取得。

C 调用使用附录 B 的 LP64 标量约定，包括整数扩展、超过八个参数后的栈传参、保存寄存器和 16 字节栈对齐。聚合通过显式指针传递，外部写入是否成功及输出是否初始化由该函数合同规定。

内部调用先按下表降低，再使用相同 LP64 标量规则：

| 源类型 | 内部降低 |
| --- | --- |
| 整数、bool、原始／函数指针 | 对应标量 |
| 零大小参数 | 无机器参数，但执行源求值 |
| 非零聚合参数 | 一个指向逐项按值快照的参数 |
| 非零聚合结果 | 第一个隐藏参数为结果槽地址，机器返回 void |
| 零大小结果 | 机器返回 void |
| `!` | 无正常返回边 |

callee 的参数有独立逻辑存储，不能借快照降低改变调用者源对象。结果槽不能覆盖仍在读取的实参快照。局部、临时、实参快照和结果槽都须满足自身类型对齐；16 字节调用栈对齐不能代替高对齐类型的存储要求。编译器不得因实际不修改而改变已规定的可观察别名／顺序。

所有外部调用默认可能读写可达的可写普通内存、有副作用，不能按纯函数删去或跨有依赖访问重排；外部汇编须按约定保存寄存器并兑现内存、设备与原子合同。语言不推断外部调用不会阻塞。

## 17 入口、panic 与平台

链接入口 `_start` 由平台提供。平台在调用语言函数前建立栈、gp/tp、静态映像、零初始化区和必要映射；没有隐式 main、堆或构造函数。代码／只读数据／可写数据分入目标的 text／rodata／data／bss 区域，构建 profile 落实权限、对齐和保留策略，不要求输出文件保留同名 ELF section header。

panic 通过固定符号 `__biomiya_panic`，按 LP64 接收消息字节地址和 usize 长度，永不返回。平台可以记录后停机或终止当前进程；不得恢复到 panic 调用之后或执行栈展开。平台独立回收进程资源不算执行源 defer。该钩子须适用于调用它的上下文，内核陷阱路径不能依赖可睡眠服务。

隐式检查失败可使用静态消息。后端若生成复制、填充或原子辅助函数调用，构建必须列出并提供这些符号及其合同；不得悄悄依赖宿主 libc、分配器或未说明系统调用。

**没有 `@trap_entry/@trap/@irq`、编译器保留 TrapFrame、专用调度转移或 arch 内联汇编。** 陷阱现场是平台普通数据结构，入口汇编负责保存机器状态、选择栈、调用普通 C ABI 处理函数并恢复／返回。CSR、页表失效、WFI 等通过显式外部汇编函数提供。

平台必须另行定义：现场字段和偏移、中断开关与嵌套、进入／离开处理函数的栈、允许修改的返回状态，以及是否支持阻塞／抢占。没有这份合同和目标测试，不能把“能调用 C 函数”当成已经支持调度。语言不对普通函数标记 IRQ-safe 或证明其完整调用链不会睡眠。

## 18 完整示例

### 18.1 具体数据与单向定型

```text
module demo;

struct Pair { left:u32, right:u32 }

fn sum(p:Pair) -> u32 {
    return p.left + p.right;
}

pub fn answer() -> u32 {
    let p = Pair { left:20, right:22 };
    let n = sum(p);
    if n == 0 { return 1; }
    return n;
}
```

这里没有泛型或未知类型求解；构造和函数签名为所有裸整数提供类型。

### 18.2 失败回滚与显式责任转交

```text
module resource_demo;

pub enum Error { Missing, Failed }
struct Ticket { id:u32 }

extern abi(C) fn platform_acquire() -> u32;
extern abi(C) fn platform_prepare(id:u32) -> bool;
extern abi(C) fn platform_release(id:u32) -> ();

fn acquire() -> Result<Ticket,Error> {
    unsafe {
        let id = platform_acquire();
        if id == 0 { return Result::<Ticket,Error>::Err(Error::Missing); }
        return Result::<Ticket,Error>::Ok(Ticket { id:id });
    }
}

fn prepare(t:Ticket) -> Result<(),Error> {
    unsafe {
        if !platform_prepare(t.id) {
            return Result::<(),Error>::Err(Error::Failed);
        }
        return Result::<(),Error>::Ok(());
    }
}

pub fn create() -> Result<u32,Error> {
    let ticket:Ticket = acquire()?;
    var armed:bool = true;
    defer {
        if armed { unsafe { platform_release(ticket.id); } }
    }
    let done:() = prepare(ticket)?;
    armed = false;
    return Result::<u32,Error>::Ok(ticket.id);
}
```

平台须实现三个外部函数：acquire 返回 0 表示未获得资源，其他值为新句柄；prepare 无论成功失败都不消费句柄；release 结束句柄责任。获得失败不释放，准备失败由 defer 释放一次，成功则由接收返回 id 的调用者承担关闭责任。语言没有把 ticket 移走或证明该责任。

### 18.3 平台入口与设备写入

```text
module boot;

const UART:usize = 0x10000000;

@export("kernel_main")
extern abi(C) fn start() -> ! {
    unsafe { core::mmio_store_u8(UART, 65); }
    loop { }
}
```

这是特定平台示例：仅当平台确实把该地址映射为允许 u8 写入的 UART 时满足执行合同。语言检查不证明设备存在。

## 19 相比 Core S 的明确取舍

| 项目 | 本草案选择 | 移除或转交的责任 |
| --- | --- | --- |
| 局部类型 | 可从确定初始化器直接得到；比较单向定型 | 不恢复统一／默认整数；接受有限不对称 |
| 模块名字 | 一套名字空间，仅模块导入 | 不支持同名类型／值和名字列表导入 |
| 常量 | 标量 const，布局前后分层 | 聚合值用 static；布局结果不反馈数组类型 |
| 错误传播 | 仅显式类型绑定语句 | 不维护任意表达式内部的错误出口 |
| 未初始化槽 | 只在 unsafe 块中显式声明 | 读取是否合法仍由作者负责 |
| 地址空间 | 一种 RAM 指针；具名地址包装放库中 | 失去语言对 user／phys／mmio 指针的部分静态区分 |
| 陷阱与架构 | 普通 C ABI 和外部汇编 | 平台维护现场和调度合同，无通用内联汇编 |
| 静态取址 | 仅本地静态根地址，不读对象即可形成 | 无子对象常量地址和初始化期 extern 重定位接口 |
| 工具接口 | 可打印类型／IR 是实现选择，不规定 Extend ABI | 不预留通用分析框架、外部手写 IR 或旧接口兼容 |

以上是本次“试拟”选择，并非用户已逐项批准的正式标准。普通值复制、手动资源管理及删除地址空间尤其需要用真实内核与自举数据结构验证；若总成本反而增加，应修订这些选择。

## 20 合规范与规模验收

以下是未来验收义务，不是已经通过的测试：

| 用例组 | 必须区分的行为 |
| --- | --- |
| 定型 | `n==0` 接受、`0==n` 无后缀拒绝；已知调用结果可省类型；无类型裸整数拒绝 |
| 常量分层 | 固定页表长度接受；布局后常量不能直接或传递用于长度；短路不能隐藏依赖环 |
| 存储 | 初始化／复制／覆盖无隐藏释放；raw 操作有授权；普通未初始化声明拒绝 |
| 顺序 | 第一个聚合实参快照不被第二实参的副作用改变；赋值右侧先于左侧定位 |
| 清理 | return／错误／break／continue 的 LIFO 清理；返回快照先保存；panic 不展开 |
| 匹配 | 标签完整、重复／冗余兜底拒绝；载荷直接定型，无递归模式 |
| 布局与链接 | 对齐、零大小、递归类型、数据重定位、静态互取址及缺失符号 |
| 平台 | C 双向调用含超八参数、实际 MMIO 宽度／fence、SC 原子与强 CAS、平台陷阱现场 |
| 代表程序 | 页分配器、句柄表、失败回滚、符号表／AST arena，以及应用事件与资源回收 |

编译器、运行时、平台、必要库、生成工具和示例分别计量，并给出总账；测试和文档另列。不能靠移目录、压行或依赖旧编译器兜底宣称缩减。自编译与在目标系统内自举分别验收。本文不承诺最终行数。

## 附录 A 语法骨架

以下 EBNF 中 `{...}` 表示重复，`[...]` 表示可选，双引号内为源记号，`IDENT/INT/STRING` 由第 2 节定义。列表允许尾逗号。它列出结构，表达式优先级、控制流头部和类型中的 `>>` 按正文定界；语法可解析不表示类型／授权合法。

```text
file        = ["module" path ";"] {"import" path ";"} {decl} ;
path        = IDENT {"::" IDENT} ;
decl        = {attribute} ["pub"] (alias | record | enumeration | function
              | constant | storage) | "static_assert" "(" expr ")" ";" ;
alias       = "type" IDENT "=" type ";" ;
record      = "struct" IDENT "{" [fields] "}" ;
fields      = field {"," field} [","] ;
field       = ["pub"] IDENT ":" type ;
enumeration = "enum" IDENT "{" variants "}" ;
variants    = variant {"," variant} [","] ;
variant     = IDENT ["(" type ")"] ;
function    = ["unsafe"] ["extern" "abi" "(" "C" ")"]
              "fn" IDENT "(" [params] ")" "->" result (block | ";") ;
params      = param {"," param} [","] ;
param       = IDENT ":" type ;
constant    = "const" IDENT ":" type "=" expr ";" ;
storage     = ["extern" "abi" "(" "C" ")"]
              "static" ["mut"] IDENT ":" type ["=" expr] ";" ;
attribute   = "@" IDENT "(" (expr | STRING | "C") ")" ;
type        = integer-type | "bool" | "(" ")" | type-path
            | "*" ["const"] type | "[" expr "]" type
            | "[" "]" ["const"] type
            | "Option" "<" type ">" | "Result" "<" type "," type ">"
            | ["unsafe"] ["extern" "abi" "(" "C" ")"]
              "fn" "(" [types] ")" "->" result ;
result      = type | "!" ;
types       = type {"," type} [","] ;
block       = "{" {stmt} "}" ;
stmt        = binding | expr ["=" expr] ";" | block | "unsafe" block
            | if-stmt | "while" expr block | "loop" block | match-stmt
            | "return" [expr] ";" | "break" ";" | "continue" ";"
            | "defer" block ;
binding     = ("let" | "var") IDENT [":" type] "=" expr ["?"] ";"
            | "var" IDENT ":" type ";" ;
if-stmt     = "if" expr block ["else" (block | if-stmt)] ;
match-stmt  = "match" expr "{" arm {"," arm} [","] "}" ;
arm         = pattern "=>" block ;
pattern     = "_" | "true" | "false" | ["-"] INT
            | variant-path ["(" ("_" | IDENT [":" type]) ")"] ;
expr        = primary | unary-op expr | expr binary-op expr | expr "as" type
            | expr "(" [arguments] ")" | expr "." IDENT | expr "[" expr "]" ;
primary     = INT | STRING | "true" | "false" | "null" | "(" ")"
            | value-path | "(" expr ")" | record-value | array-value | builtin ;
record-value= type-path "{" [initializers] "}" ;
initializers= IDENT ":" expr {"," IDENT ":" expr} [","] ;
array-value = "[" [arguments] "]" | "[" expr ";" expr "]" ;
arguments   = expr {"," expr} [","] ;
builtin     = "sizeof" "(" type ")" | "alignof" "(" type ")"
            | "offsetof" "(" type "," IDENT ")"
            | "core" "::" "ptr" "::" "<" type ">" "(" expr ")" ;
```

type-path／value-path／variant-path 是第 3、4、7 节的限定路径；固定变体另含 `Option::<T>::V` 或 `Result::<T,E>::V`。其他 core 内建按 `core::IDENT` 的调用解析，随后按专用参数规则检查。赋值左侧须是可写位置；带 `?` 绑定须有类型；只有外部函数声明可无体，extern static 禁止初始化器，本地 static 必须有初始化器。属性允许位置以第 15 节为准。

## 附录 B 目标依赖

本候选目标选择 ELF64 小端、RV64IMA＋Zicsr＋Zifencei、S-mode、soft-float LP64、静态链接，不要求浮点／向量／压缩指令或未对齐访问。设备与地址映射由具体平台确定，语言本身不固定 QEMU 的设备布局。

LP64 标量调用及原子映射使用现有 [RV64 补充](../architecture-rv64.md)所固定的 psABI 提交 `48969b7995b3ae1582f230dcce32a12d443d1a7a`，分别对应其中引用的 `riscv-cc.adoc` 和 `riscv-atomic.adoc`。这里只复用所述外部机器约定，不继承 0.5 的聚合 C ABI、特殊陷阱接口、地址空间、汇编语法或 Extend 合同。若实现改变该基线，须另修目标配置和验收，不能默默随上游变化。
