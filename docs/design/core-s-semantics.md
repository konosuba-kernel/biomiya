# Core S 最小语义方案

Core S 用显式类型、统一值复制、原始指针和语句式控制流收束核心。程序需要多写类型、传址、循环和清理协议，以减少编译器中的推导、实例化、隐式借用和多阶段重复检查。

**状态：待实施的单一设计方案。** 当前编译器和正式参考仍为 [0.5](../reference.md)。本文选择新目标名 `rv64-core-s-v1`，不宣称旧源码兼容，也不宣称已经达到数千行或完成内核移植。保留 Rust 实现、直接 RV64 汇编后端、运行平台和 Extend 只读分析接口。

用户已接受的方向是简明优先、允许繁琐、移除用户泛型与求解型推导、暂留 defer。**统一值复制、取消语言引用与资源分类、允许未初始化局部槽，以及收窄模式/常量/原子/FFI，是本方案新增的破坏性取舍。** 它们需要作为一个整体评估，不能当作用户已逐项确认或旧实现已经支持。

| 保留的能力 | 统一规则 | 移出的机制 |
| --- | --- | --- |
| 模块、具体类型与普通函数 | 声明和签名先明确，函数体只检查一次 | 用户泛型、方法、重载、类型约束求解 |
| 数组、结构体、枚举、切片 | 普通值一律复制，间接访问显式取址/解引用 | Copy/resource、隐式移动、引用与再借用、自动析构 |
| 分支、循环、错误返回、清理 | 语句式控制流、显式 return、浅层 match、?、defer | 块值、带值 break、for、递归模式矩阵 |
| 静态数据与布局查询 | 受限常量 AST 和有限依赖图 | 常量语句解释器、泛型长度与原 AST 重放 |
| RV64 内核操作 | 有限内部操作、显式执行合同 | 存储包装器、弱内存序选择、窄原子、C 聚合按值 ABI |

没有列入本文的旧语法、隐式适配和内建接口不自动继承。词法、可见性和目标机械规则仅按正文指定范围继承；所有算法和接口的工作量都计入实现，不能藏进未说明的库或 C shim。

## 1. 语义边界

- 所有普通值统一复制；无 Copy/resource 分类、隐式移动、语言引用、自动析构。
- 无用户泛型、约束求解、实例化、impl、方法、自动借用／解引用、闭包、宏和重载。
- 控制流只有语句；保留 `if`、`while`、`loop`、浅层 `match`、显式 `return`、`?` 和块式 `defer`。
- 删除元组、newtype、for／for move、范围值／范围下标、块值、带值 break、解构绑定、复合赋值。
- 保留固定 `Option<T>`、`Result<T,E>` 类型构造；它们不是可以调用用户泛型代码的入口。
- 没有 CTFE 函数、常量块、常量 if／match 或通用表达式解释器。
- 本方案整体替代对应源语义；0.5 不因本文而获得这些新规则。

## 2. 声明、名字和类型

源文件仍为 UTF-8；沿用 0.5 的标识符、注释、整数和字符串词法，不引入新词法。
文件为可选 `module path;`、导入、顶层声明；编译输入显式列文件，同模块合并并允许前向引用。
保留 `import path;` 及显式名字列表导入，无通配／别名导入、重导出、目录隐式模块和局部声明。

保留 `pub` 和 0.5 模块可见性；类型／值／模块名字空间、同域重名拒绝、内域遮蔽规则不变。
`core`、`arch`、`root` 的保留模块/路径身份沿用 0.5。预导入只包含 Option、Result、panic 和第 11 节列出的普通 core 内建；Some/None/Ok/Err 不再单独预导入。布局查询及 static_assert 仍是专用语法，不是可取地址函数；其他普通内建按声明身份识别，局部同名不会变成内建。
类型别名 `type A = T;` 透明；`struct S { field: T, ... }` 具名字段，可为空，无字段简写。

`enum E { A, B(T), ... }` 至少一个变体，每变体最多一个载荷；无字段式变体、显式判别值。
只有顶层普通函数、常量、静态对象、外部声明及 第 9 至 14 节的有限目标属性；未知／重复属性拒绝。
`fn f(x:T, ...) -> U { ... }` 的每个参数及结果必须明写类型，无缺省 unit 结果。

普通函数体、不可达语句及未被调用函数都做基础检查；普通递归调用合法，无实例化缓存。
`unsafe fn` 将调用标为 unsafe；其函数体仍需显式 `unsafe { ... }` 授权操作。
本次删除 `effects` 源语法；Extend 读取调用及目标事实，不能把源标记缺失当成不阻塞证明。

对象类型闭合集合：
`u8/u16/u32/u64/usize`、`i8/i16/i32/i64/isize`、`bool`、`()`、原始指针、函数指针、数组、切片、具名结构／枚举、固定 Option／Result。
`usize/isize` 宽度由第 13 节固定；无浮点、128 位整数、引用、元组或任意用户类型参数。

`!` 仅可写在函数／函数指针最外结果位置，不可作为载荷、参数、数组元素或指针目标。
`[N]T` 的 N 是类型为 `usize` 的受限常量；允许零长度，仍依赖 T 的合法有限布局。
`[]T`／`[]const T` 是 kernel 地址空间的固定描述符 `(data,len)`，无元素所有权与生命周期参数。

参数绑定与 let 相同，不可重新赋值；修改其指针或切片目标仍按访问合同。
原始指针须明写空间：`*kernel T`、`*kernel const T`，同样可用 `user/phys/mmio`；无省略空间形式。
函数指针为 `unsafe? extern abi(C)? fn(T,...) -> U`，非空、不捕获环境；C 调用总须 unsafe。

具名普通函数在值位置产生其完整函数指针；特殊入口及内部操作不形成普通函数值。
函数指针相容要求参数、结果、ABI 和有效 unsafe 位相同；无安全到 unsafe 的隐式适配。
类型相等展开别名，比较名义声明身份、已求值数组长度及固定构造的全部实参。

无隐式整数提升、指针 const 弱化、数组转切片、结构转换或函数 ABI 转换。
指针／切片视图转换只走第 11 节明列的有限内建；整数 `as` 是本章唯一普通转换运算。

## 3. 字面量、构造及无需求解的检查

局部绑定只准 `let name:T = e;`、`var name:T = e;` 及 `var name:T;`，不准模式或省略类型。
`let` 不可重新赋值，`var` 可赋值；绑定从初始化完成后可见，`var name:T;` 从声明后可见。
不可变拥有位置不能通过取地址后重标记指针来获得写权限；不可变指针/切片绑定所指向的可写目标仍按目标权限访问。

`var name:T;` 是本次新增取舍：分配具体槽而不隐式填零；取址／写入可填槽，实际读取前必须有完整合法 T；Core 不做流敏感初始化证明。
读未初始化槽违反执行合同；没有 MaybeUninit／移动后状态，也没有通过 let 构造未初始化槽的语法。
丢弃表达式用 `e;`；不提供 `let _`，表达式丢弃不运行析构。

表达式检查只有 `check(e, 已知T)` 与 `synth(e)`，没有未知类型变量、统一或反复传播。
绑定初始化、赋值 RHS、return、已知调用形参、具名字段／载荷提供已知期待类型。
带后缀整数直接产生其整数类型；裸整数必须在已知整数期待位置，否则拒绝，不默认 i32。

一元负号加整数幅度可以表示有符号 MIN；其他字面量越界直接拒绝。
`true/false`、`()` 和字符串直接产生 bool、unit 和 `[]const u8`；字符串是静态 UTF-8 字节，不补 NUL。
`null` 只在已知原始指针期待位置合法；不能构造函数指针或切片空值。

`S { f:e, ... }` 明定 S，每字段恰写一次，按源码字段顺序求值，禁止隐藏或重复字段。
`E::V(e)` 明定枚举与变体，载荷由声明提供期待类型；无载荷用 `E::V`。
固定构造写 `Option::<T>::Some(e)`／`Option::<T>::None`、`Result::<T,E>::Ok(e)`／`Err(e)`，所有类型实参必写。

仅这两个构造和 第 11 至 12 节单独列出的内部语法接受类型操作数；普通声明／调用无 `::<...>`。
数组 `[e,...]` 和 `[e;N]` 必须在已知 `[M]T` 位置，长度相等，元素按 T 检查；没有首元素反推。
重复构造求 e 一次再复制 N 份，N=0 仍求 e 一次；重复值不产生额外资源所有权。

无期待类型时，算术的两个操作数各自 synth 并要求同一整数类型；不以左／右兄弟反定型裸字面量。
有已知整数结果期待类型时，将该类型传给算术两侧；一元整数运算同理。
比较的 bool 结果不提供操作数整数类型，两侧各自 synth；因此 `if n == 0_u32` 合法，`if n == 0` 拒绝。

调用结果、字段、索引、? 结果由已知输入类型算出，再与期待类型比较；期待结果不能反改被调用者或输入。
`!` 调用表示该路径没有正常结果，允许用于任意已知结果位置；不是隐式对象类型转换。

## 4. 值与内存访问

初始化、读取、传参、return、赋值、构造及 match 都复制值；复制结构／数组复制全部逻辑成员，枚举仅有效标签与载荷。
复制语义不将填充或未激活载荷读成值，允许搬运其原始字节而不保证保持；复制指针／切片只复制描述符，不复制其指向对象。
覆盖和结束存储均不隐式释放；复制句柄不创建独立释放权，资源身份／别名／释放次数靠执行合同维持。

不得因可写原始指针或切片假设独占；两个别名依次访问同一合法 RAM 有确定顺序。
局部存储在所在块完成其 defer 后结束，参数存储在函数退出清理后结束；右值临时在所属完整语句结束时结束，无延长规则。
static 有程序生命周期；const 没有独立存储身份；字符串字节具有静态身份。

位置只包括局部／静态、kernel 原始解引用、位置的具名字段和数组／切片元素；无自动解引用。
`*p` 仅接受 kernel 原始指针，读取、写入和基于该原始位置取址都须 unsafe；其他空间走第 11 节内建。
字段无自动解引用；`p.field` 拒绝，`(*p).field` 合法；枚举载荷只能经 match／? 取得。

拥有聚合位置的字段／元素沿基位置可写性；const 指针和只读切片元素不可写。
`let s:[]T` 只冻结描述符绑定，元素仍可写；切片元素访问必须 unsafe，包含索引读、写及取址。
数组元素操作不要求 unsafe，除非基位置来源要求；索引只接受 usize，越界 panic，不能隐式转换有符号索引。

右值聚合可读字段／数组下标，但不可写或取址；求右值一次再复制选中成员，不延长临时。
数组伪字段只有 `.len:usize`；切片另有 `.data`，类型为与描述符相同 const 性的 kernel 指针；均只读。
数组位置 .len 不读元素，切片 .len/.data 读取描述符而不访问元素。

普通字段／下标读只读取选中成员，不预读整体；指针及切片描述符本身必须已初始化合法。
`addr_of(place)`／`addr_of_mut(place)` 不读取载荷或构造引用，后者要求可写位置。
其类型由位置确定为 `*kernel const T`／`*kernel T`；基址、索引各求一次，索引仍检查界限。

原始存储字段取址不要求字段已经初始化，但定位用的描述符和索引必须合法；不授予访问权或延长存储期。
static mut 的所有值访问／取址，及 extern static 的所有操作须 unsafe；普通 immutable static 只可 const 取址。
实际读写的存活、权限、对齐、表示、映射和同步合同见第 10 节；不满足时从该操作起超出规定语义。

调用先求 callee，再从左到右求参数；每项复制形成快照后才求下一项，最后进入函数。
聚合源码字段、数组元素、普通一元／二元操作数从左到右，各一次；`&&`／`||` bool 短路。
赋值只作语句 `place = rhs;`：先求并复制 RHS，再求 LHS 地址／索引，最后写入；不返回 unit 值。

RHS 的 ?／panic 提前退出则不求 LHS；LHS 定位失败不写入，已经发生的副作用不回滚。
原始位置赋值是类型化写入，可初始化未初始化目标，也可覆盖合法旧值，均不隐式释放。
整数保留 `+ - * / %`、包装 `+% -% *%`、`<< >> & | ^`、`~`、有符号 `-` 和整数 `as`。

普通算术溢出、除零、MIN 除／余 -1 及负号 MIN 均 panic；除法向零截断，余数与被除数同号。
包装按目标位宽截断；移位两侧同整数类型，计数不得负或达到位宽，否则 panic；左移丢高位，右移按符号扩展。
`as` 只接受整数到整数：数学值模目标 2^位宽，再以目标符号解释；无 checked_cast 或 `+? -? *?`。

`< <= > >=` 仅同类型整数；`== !=` 仅同类型整数、bool、unit、原始／函数指针，比较指针地址。
无聚合／切片相等、用户运算符、语言引用一元 &；逻辑 ! 仅 bool，不把整数当条件。
优先级沿 0.5：后缀、一元、as、乘除、加减、移位、位与／异或／或、序比较、相等、&&、||；二元左结合。

转换结果再用后缀须括号；删除范围／赋值表达式后不再需要块表达式后续 `* & -` 的特例。

## 5. 纯语句控制流与浅层 match

块只含语句，无尾表达式；普通表达式必须 `;`，块／if／match／while／loop／unsafe 块自身无需分号。
`if bool { ... } else { ... }`、`while bool { ... }`、`loop { ... }` 均是语句；条件每次按通常顺序求值。
`break;`／`continue;` 指向最近循环，循环外拒绝；无标签、带值 break、for 或 range。

`return e;` 必须写 e（包括 unit）；先形成完整返回快照，再清理退出作用域。
不用数据流求解返回类型：每函数签名已知，用语法树计算“可能到达块末尾”这一布尔量。
return 和 ! 调用无正常后继；顺序组合、if 两臂的或、穷尽 match 各臂的或；缺 else 保留正常后继。

while 总保留正常后继；loop 仅当语法中存在指向它的 break 才保留后继，包括不可达 break。
不按常量条件或 defer 是否必然 panic 优化这一判定；函数可能到达末尾则拒绝，unit 也需 return。
所有不可达代码仍检查名字／类型／unsafe／上下文，不提供新的正常路径。

第 14 节的特殊上下文转移仅作末尾独立语句或 `return transfer(...);`，尾位置只沿最终嵌套块／if／match 臂传播，禁止循环／defer／其他表达式嵌套；先快照参数再清理。

`match e { pattern => { statements }, ... }` 先复制 e 一次，按源码顺序选择首个命中臂。
允许 bool 的 true／false、整数的同类型可表示字面量、枚举完整路径变体、最后 `_`。
载荷模式只能 `E::V(name:T)` 或 `E::V(_)`；T 必写并与声明载荷完全相同，绑定为 let，作用域为该臂。

固定 Option／Result 模式也必须写完整路径，如 `Option::<u32>::Some(name:u32)`、`Option::<u32>::None`、`Result::<u32,Error>::Err(error:Error)`；模式写出的类型必须与被检类型完全相同。所有变体都不允许省略所属类型。
无递归模式、载荷字面量、顶层绑定模式、结构体模式、范围／或模式、模式守卫或借用匹配。
整数必须有最后 `_`，即使逐列写全窄整数值；bool／枚举可覆盖全部顶层值，或用最后 `_`。

重复字面量／变体、多个 `_`、`_` 后续臂拒绝；覆盖就是 bool 两位或枚举变体位集，无递归矩阵。
嵌套判断须先绑定载荷，再在臂内写另一个 match；不允许跨臂共享 payload 绑定。

## 6. 错误传播与退出清理

`e?` 仅对已知 `Result<T,E>`，当前函数结果必须为 `Result<U,E>`，E 精确相同，无隐式错误转换。
复制 e 一次；Ok 复制载荷成为 T；Err 复制 E 构成当前函数 Err 返回快照，执行正常退出清理。
`?` 在表达式任何合法操作数位置可用，错误立即停止其余操作数求值；const／static 初始化及 defer 内拒绝。

return／? 退出到函数，break／continue 退出到目标循环；所有退出共用作用域清理展开。
块自然结束也清理；continue 每轮退出循环体，下一轮重新建立存储及注册记录。

只保留 `defer { statements }`，删除 0.5 的 defer-call 形式（旧形式也在退出时求值，并非注册时快照）；执行到 defer 语句才注册当前块动作。
注册不求清理体中的表达式；动作在退出时按绑定当时值执行，只能引用注册点已经可见的名字。
一块内按注册逆序，内块先于外块；变量存活至该块所有动作结束，之后才结束存储。

defer 体允许普通表达式／赋值、带初始化局部、嵌套块、if、浅层 match 和 unsafe；不准循环或未初始化声明。
defer 体及其嵌套块不准 return、?、break、continue、defer 或目标上下文转移；被调用普通函数可自己正常 return。
条件注册位于所执行分支块，在该分支退出时执行；跨分支延后条件释放须在外块注册并使用显式 bool 状态。

return 快照先于清理，所以清理改动原局部不改变已复制返回值；Err 快照同理。
动作中 panic／不返回的普通调用停止该路径；panic 不展开、不执行剩余 defer，也不能捕获。
每次动态块内各注册点最多执行一次，循环体是每轮新块；编译器跟踪已激活注册点并在各结构化出口静态列出清理动作，无须运行时 flag 或可增长清理栈。

## 7. 常量与布局依赖

常量 AST 的白名单只有整数／bool／unit／字符串／null、const 名字、具名函数值、聚合构造、数组重复、整数运算／as、比较／逻辑。
常量比较仅允许同类型整数的序／相等比较及 bool／unit 相等比较；不准指针／函数地址比较，包括 null 或同一符号地址，重定位不须转为编译期数值。
另准 `sizeof(T)`、`alignof(T)`、`offsetof(S,field)` 和本单元已定义 static 的静态地址／字段／常量数组下标取址。

静态 mutable 对象只能用 `addr_of_mut`／`addr_of` 取址并须显式 unsafe；常量上下文仅准 `unsafe { addr_of_mut(static-place) }`／`unsafe { addr_of(static-place) }` 两种专用形式。
上述专用形式是常量取址节点，不接受其他语句／尾表达式；不得借此引入一般块解释。
const 名字允许取得已求出的常量值并连到 C 节点，不读取存储；禁止 static 值读取、聚合字段读取、常量下标读、原始解引用、普通调用、局部绑定、控制流、?、defer 或一般 unsafe 块。

`const A:u32 = 1; const B:u32 = A;` 合法且 B=1_u32；`static A:u32 = 1; const B:u32 = A;` 拒绝 static 值读取。
固定 Option／Result 构造合法；数值地址构造、ptr_const、原始切片构造及全部机器内建不在常量白名单，须运行时执行。
`.len` 只准数组类型已知的数组位置或字符串字面量：它是静态长度查询，不读取容器／static 初始化值。

不准常量读取切片变量 .len 或任意表达式 .len；需要重复使用长度就定义显式 `const N:usize = ...;`。
`sizeof/alignof` 只接受对象类型；`offsetof` 只接受具名结构单个可见字段，不接受递归路径／枚举载荷。
`const NAME:T = C;` 及 `static mut? NAME:T = C;` 的 T 必写，C 按 T 检查，static 不准无初始化器。

`static_assert(C);` 仅模块级，C 必须为 true 的常量 bool；无函数内断言执行／解释。
白名单检查所有子树；常量运算用运行时位宽规则，失败变编译错误；&&／|| 只求需要的一侧。
依赖收集仍覆盖两侧及所有构造元素，包括零重复元素；不能以短路或零长度删除循环边。

常量 evaluator 只递归此白名单 AST，无执行帧、语句、用户调用、跳转或内存读取；总步骤受有限输入及数组输出大小约束。

先收集全部声明、透明展开别名；别名引用图遇到任何别名即加边，穿过指针也加边，别名环一律拒绝。
具名结构／枚举作为身份边界停止别名展开，故 `struct Node { p:*kernel Node }` 合法。
建立节点 `C(name)` 常量值、`N(每个数组长度出现)`、`A(每个 align 参数)`、`L(每个具体对象类型)`、`I(static)` 初始化。

建图时数组类型键使用长度出现 N 的身份，不先求长度；拓扑计算 N 后才规范化数组长度、完成类型相等检查。
数组长度／align 参数的类型均检查为 usize，所有类型出现中的 N 和 A 都成为根，不因位于指针目标／未用函数而跳过。
每个声明的对象布局、每个 C/I/assert，以及每个 sizeof/alignof/offsetof 查询也作为根，未使用声明同样检查。

依赖方向为“请求者 → 所需节点”：const 引用到 C，长度到 N，align 到 A，布局查询到 L，static 初始化到其 C／查询／构造依赖。
`L(数组)` 连 N 与元素 L；`L(结构/枚举/Option/Result)` 连所有按值字段／载荷 L 及其 A；零数组也连元素 L。
`L(指针/切片/函数指针)` 只连目标固定表示事实，不连目标／签名类型 L；目标类型内的 N/A 仍独立检查。

`L(具体具名类型)` 使用声明身份缓存；固定 Option／Result 使用完整实参缓存；遇到正在展开节点记回边，不继续无限展开。
字段静态地址连根对象 L 与该字段偏移；数组静态地址还连下标常量及数组长度，检查边界与地址计算溢出。
取 static 根地址只依赖符号及根对象 L/A，不连 I；禁止把 static 初始化值当常量，故两个 static 相互取址合法。

例如 `struct Link { next:*kernel const Link }` 与 `static X:Link = Link { next:addr_of(X) };` 是合法重定位自环，非值依赖环。
对上述有限图做 DFS 三色或 SCC，任何可达循环均拒绝；拓扑序计算值／长度／布局，再检查大小、对齐及对象初始化。
`const N:usize = sizeof(A); struct A { x:[N]u8 }` 的 C→L→N→C 必拒绝，不靠求值请求顺序或死分支侥幸接受。

`struct Bad { next:Bad }` 必拒绝；仅指针递归不构成 L 环；数组大小／偏移必须符合目标 usize 可表示范围。
布局机械计算由第 13 节固定，依此有限图请求一次，不允许布局调用用户函数或反向驱动表达式推导。
static 初始化只发数据与重定位，无执行代码、懒初始化或声明顺序；运行前所有初始化镜像建立，.bss 由第 9 节启动合同兑现。

external static 无 I 节点，只有第 13 节明定的对象／边界符号合同；不准用于常量静态取址规则。

## 8. 正反例与迁移代价

以下是语言设计例，不宣称当前编译器支持；`prepare`／`release` 为应用自己的具体普通函数签名，非隐藏泛型库。
```text
struct Ticket { id:u32 }
enum Failure { Bad }
// 已声明：fn prepare(t:Ticket) -> Result<(),Failure>；fn release(t:Ticket) -> ()。
fn finish(t:Ticket) -> Result<Ticket,Failure> {
    var pending:bool = true;
    defer { if pending { release(t); } }
    let done:() = prepare(t)?;
    pending = false;
    return Result::<Ticket,Failure>::Ok(t);
}
fn sum(a:u32, b:u32) -> u32 { return a + b; }
fn select(v:Option<u32>) -> u32 {
    match v { Option::<u32>::Some(x:u32) => { return x; }, Option::<u32>::None => { return 0; } }
}
```
finish 的 Err 路径先保存错误，再 release 一次；Ok 路径清理时 pending=false；panic 路径无清理保证。
若调用 release 之后又使用 t，Core 不以句柄复制语法拒绝，但实际使用已释放资源违反应用／底层操作合同。
`let n = 1;`、`if n == 0`、`fn f()->u32 { 1 }`、`loop { break 1; }` 全拒绝。

`match v { Option::<u32>::Some(0_u32) => {}, Option::<u32>::None => {} }` 拒绝载荷字面量模式；先 `Option::<u32>::Some(x:u32)` 再比较或嵌套 match。
`defer { prepare(t)?; }`、`const N:usize = f();`、`const N:usize = if true {1} else {2};` 全拒绝。
`const SAME:bool = addr_of(X) == addr_of(Y);` 拒绝地址常量比较；运行时同类型原始／函数指针比较仍合法。

`let p:*kernel u32 = addr_of(n);` 拒绝 const／mutable 类型不符；`addr_of(1_u32)` 拒绝非位置。
`var slot:Ticket; unsafe { /* write(addr_of_mut(slot),t) 可初始化具体槽 */ }` 不产生析构或隐藏分配。

移除整套机制：实例化与递归实例检查、类型变量统一／默认修复、Copy/resource 结构分类、移动状态、引用与再借用、方法接收者搜索、模式矩阵、块结果／循环结果合流、常量语句解释器。
保留算法：名字解析／别名无环、已知类型双向检查、有限对象布局、受限常量 DAG、位置读／写区分、标签位集覆盖、结构化可达性、显式退出清理和目标降低。
迁移需展开泛型为具体函数／类型，以普通函数及显式取址替代方法，以 while 替代 for，用具名结构代替元组，并重写常量控制流为有限标量公式／明确常量。

统一复制可能复制大聚合并产生句柄别名；改用原始指针传递可降低成本，但初始化、有效期、同步及单次释放责任更显式。
无语言借用／所有权保证；Extend 可读源位置、声明／类型身份、实际复制／地址／访问、控制流、defer 和目标事实，不得假装旧 Ownership/Borrow 保证自动保留。

## 9. RV64 目标与继承范围

设计名 `rv64-core-s-v1`，不是 `rv64-core-v1` 的源兼容别名。继承 [0.5 RV64 目标补充](../architecture-rv64.md) R1 的 ELF64 小端、RV64IMA+Zicsr+Zifencei、S-mode、soft-float LP64、静态链接、16 字节调用栈对齐、平台 `_start`、节及链接重定位规则；继承固定 psABI 提交及旧 R5/R6 的运行时物理 ABI、TrapFrame 和无调度陷阱合同。不增加 ISA、抢占或平台能力。
改动源合同：所有普通值复制；无引用、隐式移动、Copy/resource、自动析构、方法或用户泛型；删除 MaybeUninit/UnsafeCell/Atomic 包装器、MemoryOrder、窄/usize/指针原子实例、packed/newtype/tuple 布局及 C 聚合按值传参。固定切片和枚举仍可存在。
存储初始化、别名、同步、设备协议及句柄责任由实际访问合同维护；Core 检查类型、位置和 unsafe 授权，不保证唯一释放、不泄漏或无悬垂。不能继续宣称旧 Borrow/Ownership 的引用/移动保证自动适用。

## 10. 存储与指针合同

`*kernel T` / `*kernel const T` 是内核虚拟地址；`user`、`phys`、`mmio` 保留相同拼写和 64 位地址表示。只允许 kernel 普通解引用；user 必须由显式平台函数进行故障可恢复的用户拷贝，phys 必须由平台建立映射，mmio 必须用本方案内建。重新标记地址不能替代这些步骤。
原始地址可以为零、未映射、未对齐或悬空；形成/复制地址不访问内存。实际读写须非空、自然对齐、完整范围存活且有映射和读写权限；读要求初始化及合法表示，写不要求旧内容合法。零大小访问仍要求非空、对齐和存活的逻辑对象身份，不访问字节。
`*p`（仅 kernel）形成位置，读取复制 T，写入复制新 T；两者 unsafe。const 指针禁止写入。覆盖旧值不释放资源；读取不使源未初始化。指针目标之间不自动产生 noalias/restrict 或按类型不别名假设。

原始存储可以是平台分配的字节区或具体类型的未初始化槽；不需要包装器。对齐、范围、初始化事实均独立于指针类型。`var slot: T;` 分配 T 大小/对齐的槽，不隐式零填充；只能在完整初始化后读取。任意 raw 写入的初始化事实不由 Core 证明。
也可定义 `@align(4096) struct PageBytes { bytes: [4096]u8 }`；合法字节区允许通过数字地址重新解释成具体对象，访问仍须逐次满足完整合同。字节填零不自动证明任意 T 合法；尤其函数指针零值和非法枚举标签不得读取。
字段取址不读基址指向的聚合，可逐字段写入未初始化结构；数组元素同理。所有字段/元素完成合法初始化后才能读整个聚合，填充除外。不能通过未初始化枚举载荷投影初始化：枚举用完整变体值写入；只有合法活动标签的载荷可投影。

填充及未激活枚举载荷可含任意字节；聚合复制可搬运这些字节，但不能将它们当用户字段读取。字节复制可以搬运未初始化字节并保留其未初始化事实，不把它们变为合法值。
切片是复制的地址/长度描述符，不是语言引用。`[]T` 可写，`[]const T` 只读；二者只描述 kernel 普通 RAM。形成切片要求非空对齐地址、`len*sizeof(T)` 可由 usize 表示、完整存活范围及对应权限，全部元素是合法已初始化 T；空切片可用对齐哨兵或一过尾地址，无元素访问权。后续访问仍须存活及同步。
切片下标检查失败 panic；通过切片读/写元素是 unsafe，防止用安全下标绕过原始存储合同。`.len` 与 `.data` 只读描述符，分别为 usize 与相应 const 性的 kernel 指针；不访问元素。复制可写切片不授予独占，也不复制元素。

从局部/静态取址不延长寿命；保存一个稍后失效的指针不等于已经进行无效访问。执行非法读取、竞争或无效机器操作从该操作起超出规定语义；检查失败仍是 panic。

## 11. 内部操作接口

下表的 T/P 是文档元变量，不是用户可声明的泛型。内建有保留声明身份、不能取函数指针。T 必须是具体有限大小对象类型；由第一个已知指针/位置操作数直接选择，其余操作数须与该 T 完全相符。不反推未知类型，不查找用户操作，不重放用户代码。所有普通值实参从左到右各求值一次并保存，随后执行操作；取址实参按位置规则计算一次。布局操作数不求值为普通值。

除专用布局语法外，表内名字可加 `core::`；`ptr::<T,space>` 是唯一数值指针构造的固定语法，其中 space 明写四个地址空间之一。`panic(message:[]const u8)->!` 是固定内建，调用无须 unsafe；行为见第 14 节。不保留旧 replace/swap/forget/split_at_mut/checked_cast 或任何未列出的包装器成员。

| 固定族签名 | 类型选择与行为 | unsafe |
| --- | --- | --- |
| `addr_of(place:T)->*kernel const T`; `addr_of_mut(place:T)->*kernel T` | 已知位置 T；后者须可写；不读目标或先构造引用；局部/本地不可变静态的普通位置取址安全，原始位置/static mut/extern static 取址 unsafe | 按来源 |
| `addr(p:P)->usize` | 任意原始指针，保留地址位 | 否 |
| `ptr::<T,space>(a:usize)->*space T` | 专用语法：显式具体 T、kernel/user/phys/mmio 标记；无默认空间；零得到空指针 | 是 |
| `ptr_const(p:*space T)->*space const T` | 同空间同目标只读弱化；除此之外无隐式指针转换 | 否 |
| `ptr_add(p:P,n:usize)->P`; `ptr_add_bytes(p:P,n:usize)->P` | 已知 P；保留空间/const/T；分别加 n*sizeof(T) / n；乘加溢出 panic；可越界计算，不授予访问权 | 是 |
| `read(p:*kernel const T)->T`; `write(p:*kernel T,v:T)->()` | 与普通 raw 读/写相同；read 的可变指针须显式 ptr_const | 是 |
| `copy_bytes(dst:*kernel u8,src:*kernel const u8,n:usize)->()` | 全范围已映射/存活/有权限；按调用前字节快照拷贝，允许重叠；保持未初始化事实；n=0 不访问字节 | 是 |
| `fill_bytes(dst:*kernel u8,v:u8,n:usize)->()` | 同样范围/权限；初始化每字节；不保证目标 T 合法；n=0 不访问字节 | 是 |
| `slice_from_raw_parts(p:*kernel const T,n:usize)->[]const T`; `slice_from_raw_parts_mut(p:*kernel T,n:usize)->[]T` | T 取 p 的目标；满足第 10 节切片合同 | 是 |
| `sizeof(T)->usize`; `alignof(T)->usize`; `offsetof(S,field)->usize` | 显式具体类型，field 为具名结构字段；常量依赖及静态 initializer 白名单见第 7 节 | 否 |
| `volatile_load(p:*kernel const I)->I`; `volatile_store(p:*kernel I,v:I)->()` | I 为现存整数类型；自然对齐的一次同宽机器读/写，不可合并/删除/拆分；满足普通 RAM 合同 | 是 |
| `mmio_load(p:*mmio const I)->I`; `mmio_store(p:*mmio I,v:I)->()` | I 同上；一次同宽访问；满足设备方向/宽度/状态/权限合同，设备不套普通 RAM 初始化模型 | 是 |
| `atomic_load(p:*kernel const U)->U`; `atomic_store(p:*kernel U,v:U)->()` | U 只能 u32 或 u64；所有操作都是 SC，无 order 参数 | 是 |
| `atomic_exchange(p:*kernel U,v:U)->U`; `atomic_compare_exchange(p:*kernel U,expected:U,next:U)->U` | 返回旧/观察值；强 CAS，仅观察值==expected 时写 next，无伪失败 | 是 |
| `atomic_fetch_add/sub/and/or(p:*kernel U,v:U)->U` | 四个有限名字；返回修改前值；add/sub 按 U 位宽包装 | 是 |

没有独立指针强转：用 `ptr::<Dst,space>(addr(p))`，需要 const 结果再用 ptr_const。改变空间、目标或恢复可写拼写不会改变物理地址、建立映射、解除只读页或重新获得寿命/资源责任。user 数值还须平台用户拷贝；phys 数值还须真实映射；仅同值 kernel 重标记不能充当映射函数。
没有未对齐类型化读写内建和 packed；字节协议用 u8 读写与移位组装具体整数。普通内存复制不对 MMIO 或活动原子槽合法；大块移动由 copy_bytes 表达，不依赖不存在的库/宿主 C。

## 12. 原子、同步与架构族

原子槽就是独立自然对齐的 u32(4/4) 或 u64(8/8) RAM 区，无隐藏布局。先在未发布、独占阶段用普通写初始化；发布后到全部用户静止并重新获得独占权之前，同一槽只允许同宽原子操作，禁止普通/volatile/MMIO 访问及包含该槽的普通聚合复制。指针可复制不允许复制活动原子存储。
不同 hart、可重入的 IRQ/trap 都是执行上下文；冲突普通访问（至少一个写）没有 happens-before 或平台互斥时违反执行合同。静态对象不自动提供互斥，指针 const 不证明目标无并发写；共享可变静态与普通指针别名均受此合同约束。
源模型只保留旧 reference 22 的 SC 子集：每槽修改序包括初始化；全部原子操作参与一致全序 S，保持源序与各槽修改序；读看到 S 中此前最近修改/初始化；RMW 读紧邻前驱，失败 CAS 只读。SC 读有 acquire，写有 release，匹配观察建立 sw，hb 是源序与 sw 的传递闭包；禁止循环凭空制造值。具体沿用旧固定 N4861 基线的 SC/coherence 要求，不引入 C++ 生命周期/类型别名规则。

后端沿旧 psABI 原子映射或等价映射实现真正 SC；允许 AMO/LR-SC 重试，强 CAS 内部重试保留集丢失；无分配、睡眠锁或 wait-free 承诺，IRQ/trap 可用。普通 volatile/设备 fence 不建立原子 sw。
删除 u8/u16 原子：每个逻辑窄值用其独占 u32 槽，取值后显式掩码；不能把旧紧凑布局中的相邻字段当 32 位槽。继续不提供有符号原子：用等宽无符号位表示及显式转换。删除独立 usize 原子接口：用 u64 槽并显式转换，RV64上位宽相同。删除指针原子：用 u64 地址槽、addr/ptr 重建，空值用 0；目标对象发布/回收另需协议。不能原子更新聚合或混合宽度；用 u32 锁保护普通聚合。无独立 atomic_fence，须通过真实原子发布/获取协议同步。

以下 arch 名字保留，不能取函数指针，CSR number 是编译期已知 usize。每次架构操作保持源序、有副作用、作为编译器普通内存屏障；仅标有硬件 fence 的接口提供相应机器顺序。

| 固定签名 | 机械行为与检查 | unsafe |
| --- | --- | --- |
| `arch::riscv::cpu_relax()->()` | nop，不调度/睡眠 | 否 |
| `arch::riscv::wfi()->()` | WFI，可提前返回；等待/可能阻塞，禁止 trap 链调用 | 是 |

| `arch::riscv::csr_clear_bits(number:usize,mask:usize)->usize`; `csr_set_bits(number,mask)->usize` | 各一次 CSR 原子读改写，返回旧 CSR；第二个完整路径也在 arch::riscv 下 | 是 |

CSR 白名单沿旧 R7：0x100 sstatus、0x104 sie、0x105 stvec、0x140 sscratch、0x141 sepc、0x142 scause、0x143 stval、0x144 sip、0x180 satp。其余编译失败；写/RMW 仍须维持保留位、权限、WARL、映射和活动帧合同。
汇编保留唯一专用表达式 `arch::asm(STRING,in("a0") value,out("a1") place,clobber("t0")) -> ()`，整式 unsafe。输入仅整数/bool/原始指针；输出仅这些类型的可写位置，可尚未初始化；具体类型来自已声明位置，无类型反推。先按出现顺序求值保存全部输入，再按出现顺序保存全部输出地址，执行，最后按输出顺序写回。
沿旧 R8 的 a0-a7/t0-t6 集合、同寄存器最多一输入一输出、输入/输出扩展及 bool 必为0/1、局部数字标签、无 NUL 模板、无函数调用/外部符号/数据指令/非局部控制流/改 sp/ret/SRET、clobber 完整合同。汇编器与 unsafe 作者负责指令合同；Core 不解码证明机器代码。无纯汇编/nomem/noreturn/自动寄存器约束。一律副作用+编译器内存屏障，默认不插硬件 fence；允许模板修改内存但仍遵守原子/设备/存活协议。

删除旧源 `effects` 语法不解除运行限制；wfi、等待型汇编、未知外部服务是否可在 trap 调用由作者/平台承担，Extend 可只读检查显式事实。trap 禁止等待/睡眠/调度/主动启用 SIE，即使汇编可表达相应指令也不合法。

## 13. 布局、静态与 ABI

属性闭合集合为 `@repr(C)`（结构体）、`@align(N)`（结构体/枚举类型或本地定义的静态对象）、`@section("name")`（函数/静态定义）、`@export("name")`（函数/静态定义，包括特殊函数）、`@irq`/`@trap_entry`/`@trap`（特殊函数定义）。属性不用于字段、参数、局部绑定或别名；重复、未知、非法位置及互斥组合编译失败。三个特殊函数属性互斥，也不能与 C ABI 并用；特殊函数的 export 仅提供平台可链接符号，不开放普通源调用或函数指针转换。导出名在本编译单元中唯一，外部定义冲突最终由链接器拒绝。

整数二补码、大小/对齐为位宽/8；usize/isize=8/8；bool=1/1且仅0/1合法；原始/函数指针=8/8，函数指针不得零（空槽用固定枚举或显式 stub）。unit/空结构=0/1。普通结构按声明顺序逐字段向上对齐，最终 sizeof 对齐到最大字段对齐，无重排/niche。
数组 `[N]T` 连续，步长 sizeof(T)，align=alignof(T)；N=0 仍保留元素对齐。切片16/8，地址偏移0、usize长度偏移8。零大小对象地址可相同，不从地址相等推导对象身份。
枚举 u32 标签按声明序从0编号；变体载荷按结构布局，载荷起点对齐到最大载荷对齐，联合大小取最大；整体 align=max(4,载荷align)，sizeof 尾部向上对齐。非法标签不能读；无载荷/非活动载荷不要求初始化；变体数超过2^32拒绝。Option/Result 使用同一固定枚举布局，不利用空指针 niche。

固定类型的变体事实明确为：`Option<T>` 的 `Some(T)` 标签为 0，`None` 标签为 1；`Result<T,E>` 的 `Ok(T)` 标签为 0，`Err(E)` 标签为 1。这是两个封闭类型构造的定义，不引入用户泛型声明、Copy 属性或自动资源处理。

`@align(N)` 支持1..4096的2次幂；类型属性提高类型对齐并尾部取整，对象属性只提高该对象地址对齐。布局加/乘/向上取整溢出 usize 编译失败。无 packed。
`@repr(C)` 只允许具名结构（整数/bool/kernel数据指针/C函数指针、递归此类非空结构与正长度数组字段），LP64自然字段布局；不开放 union/bitfield/flexible-array/空C结构，不能组合 @align。C可按此布局通过指针访问；通过其他对象指针并不授权 C 读取该对象表示。
`static` 只读，`static mut` 可写且读/写/取址 unsafe；初始化器常量与依赖见第 7 节，无运行时构造。只读常量/静态 .rodata，可写初始化数据 .data，可零填充者 .bss；删除内部可变包装器，不允许通过指针写本地只读对象。

`@section` 的非空无NUL节名、`@export` 的符号及 `__biomiya_` 保留前缀沿旧R1；权限不可由节名推断。链接脚本负责映射、对齐、KEEP/排序和边界；未满足构建失败。外部 static 不分配存储；其声明须具体合法布局，实际访问由平台保证。
链接地址符号可声明 `extern abi(C) static BOUND:u8`，仅 `addr_of(BOUND)` 不加载字节，也不要求存在可读对象大小；读取仍需真实存储合同。外部符号/本地静态取址按链接重定位处理，取址白名单见第 7 节。
普通 ABI 沿旧R3机械降低：标量按LP64；零大小参数省略机器参数但仍求值；非零聚合按值快照地址，聚合结果为首个隐藏结果槽指针、机器void返回；never无返回边。快照必须在每个实参求值时建立，不能等后续副作用后再复制；callee 参数是独立逻辑位置，切片只复制描述符。结果槽不与仍在读的快照重叠。

C 源签名仅允许整数、bool、kernel数据指针及具有同样 C 签名的 C 函数指针参数/结果；unit仅结果表示void。无聚合/枚举/切片/其他空间指针/never按值，无 variadic。C函数指针与普通函数指针不互转；C调用（含间接）unsafe，导出的C函数由声明者维护外部执行合同。
LP64 标量扩展、超过8参数后的栈传参、保存寄存器及对齐必须完整实现；不会因删除聚合C签名缩成“只支持八参”。聚合通过显式 `*kernel [const] S` 传入/传出，外部函数按协议返回标量状态码，不能依赖未定义 shim。

## 14. Panic、入口与陷阱

平台 `_start` 完成映像/.bss、16字节栈、gp/tp、映射后，可调用 `@export("kernel_main") extern abi(C) fn kernel_main()->()`。无隐式main。
panic 沿旧 `__biomiya_panic(message_address:*kernel const u8,message_length:usize)->!` 的物理LP64两参数ABI；平台记录/停机/重启，永不返回，不展开、不执行用户defer、不调用睡眠服务。后端复制/原子等辅助符号须列出且由最终构建提供，也不得引入睡眠、分配、构造函数或未说明系统调用。
`arch::TrapFrame` 公共 C布局不变：x:[32]usize、sepc、sstatus、scause、stval，偏移0/256/264/272/280，sizeof288、align8；平台可额外align16。x0=0，x2是被中断sp；后两字段是故障快照，返回桩不以其写硬件。

源特殊签名改为 `@trap_entry fn e(frame:*kernel arch::TrapFrame)->!`、`@trap fn h(frame:*kernel arch::TrapFrame)->()`、`@irq fn h(frame:*kernel arch::TrapFrame)->()`；无语言引用。三者不能普通调用/取函数指针；物理入口仍a0帧地址及普通保存规则。

平台构建输入须明确选择唯一入口导出名，例如 `@export("kernel_trap_entry") @trap_entry fn entry(frame:*kernel arch::TrapFrame)->!`。编译器检查被选声明的属性、签名及符号唯一性；缺少选择、选择非入口或符号冲突均构建失败。保留现有硬件桩的 `call __biomiya_trap_entry` 时，由平台链接脚本显式绑定 `__biomiya_trap_entry = kernel_trap_entry;`，或由平台桩直接调用该导出名；两种路径均遵守 a0 帧指针 ABI。保留前缀只用于平台别名，用户导出仍不得占用它。入口选择和实际别名/桩列入构建输入与报告，不能以普通函数调用、C shim 或隐式 main 代替硬件入口。

`arch::enter_trap_handler(frame:*kernel arch::TrapFrame,named_handler)->!` / `arch::enter_irq_handler(...) ->!` 是 unsafe 尾转移内建，仅 trap_entry 尾部；具名第二操作数必须具有相应属性和同帧签名，不是可保存的源函数指针。帧须当前活动帧，不可局部仿造。先保存帧地址，然后执行该退出路径的defer/结束局部槽，再进入旧 `__biomiya_dispatch(frame_address,handler_address,kind)->!`（kind0/1）物理 ABI；handler 正常返回先执行自己的defer，再平台SRET。
硬件入口桩负责保存整数状态、内核栈、gp/tp、每hart帧/嵌套；处理期间SIE关闭。故障嵌套须保存/恢复活动帧或可靠panic，不能覆盖未处理帧。返回维护合法sepc/sstatus/x1-x31、映射/栈/权限并释放活动记录；帧指针在该次返回后失效。指针复制不证明当前帧身份或延长其寿命。

严格保留旧R6：trap/IRQ链不得调度、睡眠或主动开启中断；包括普通函数、FFI和汇编间接调用链。延后到普通检查点调度改变时延，不是时钟抢占；实际抢占/可睡眠系统调用须另命名配置并定义帧/栈切换，本配置不提供它。

## 15. 代表操作与资源责任

页表条目：定义 `@align(4096) struct PageTable { entries:[512]u64 }`；平台page_alloc取得4096对齐/大小的存活RAM，失败返回空指针；fill_bytes全页为0，再通过addr+ptr重建PageTable指针。0表示平台Sv39无效PTE，未发布阶段初始化完成。子页表先初始化并保持存活，然后用atomic_store写发布的父表具体entry：`atomic_store(addr_of_mut((*table).entries[index]),encoded_pte)`。index按固定数组检查；对有效位/物理页号/权限及硬件A/D更新须遵守平台Sv39协议（并发更新用CAS保存需保留位）。修改后本hart sfence_vma_all，其他hart通过显式失效确认后方可回收旧页；纯指针重标记无此保证。

IRQ-save锁的完整顺序（所有 raw/CSR/atomic 操作在 unsafe 中，锁槽独占u32且预先初始化为0）：
1. `saved:usize = arch::riscv::csr_clear_bits(0x100,2)` 一次读取旧sstatus并清SIE；不是read后write的窗口。
2. 循环 `atomic_compare_exchange(lock,0,1)`，观察0才获得锁；否则cpu_relax；持锁内访问普通受保护数据。
3. 正常退出用显式 unlock 或 defer：先 `atomic_store(lock,0)`，再仅当saved&2非零执行 `csr_set_bits(0x100,2)`。清理按此单个函数顺序展开，不把开中断放在释放前。
4. 嵌套irq-save按LIFO恢复；持有区禁止主动启用SIE、睡眠或调度。trap内saved的SIE为0，所以不会主动开中断。panic不解锁/defer，平台应停机而非继续执行。跨上下文锁交接必须显式协议，不能让词法defer提前释放。

MMIO：`reg:*mmio u32=ptr::<u32,mmio>(mapped_device_address)`；准备DMA描述符普通RAM后device_write_fence，再`mmio_store(reg,command)`；如设备要求命令后顺序再执行device_write_fence；读`mmio_load(ptr_const(status_reg))`并按设备协议调用device_read_fence后读已完成的DMA RAM。宽度/方向及顺序来自具体设备协议；设备fence不代表DMA已经完成，完成前不得释放缓冲区。映射由平台完成，物理数值不冒充设备虚拟地址。

C聚合：`@repr(C) struct Request { base:*kernel u8, size:usize }`；调用 `extern abi(C) fn submit(req:*kernel const Request,out_id:*kernel u64)->i32` 时传addr_of(req)/addr_of_mut(out_id)，返回0后才可读已写out_id；非0状态必须按此具名函数合同处理，不假定输出初始化。所有传参分别求值一次；Request不按值经C。

显式 ctx+ops：具体 `FileOps` 结构字段为 `unsafe fn(*kernel u8,[]u8)->isize` read、`unsafe fn(*kernel u8)->()` retain/release；`FileHandle` 保存ctx:*kernel u8与ops:*kernel const FileOps。读先复制(*ops).read指针，再显式调用(ctx,buffer)；具体驱动包装函数用addr+ptr恢复其具体State类型，检查合法配对/存活并实现实际操作。接口无需trait/用户泛型/方法；ctx和ops配对与最后引用销毁不是类型保证。

失败回滚与句柄转交的准确展开：分配FrameRange后登记带布尔armed状态的defer，失败出口若armed则release；初始化DMA描述符/映射表之前保持armed=true。插入成功后表接管释放责任，显式armed=false；插入失败保持true或显式release后置false。map_remove(map, key)先在锁内取走具体记录，释放锁后release，不能在锁内运行可能再次取锁的销毁。FD duplicate/get调用retain；insert“消费责任”只在成功后生效；replace先保存旧句柄再安装新句柄，解锁后release旧句柄；close清空槽再release。表销毁显式逐个release。
上述“转交”都是执行协议：普通赋值/按值参数仍复制句柄，Core不把源置空或防止重复release；调用者必须显式清空/标记旧槽并停止再使用旧责任。复制独立句柄前须retain，观察性副本不得release；泄漏/双重释放及并发回收风险由库合同/可选证明承担，不能假装旧移动所有权检查仍在。


## 16. 单一语义检查与编译器结构

建议数据流为：源码 → token/AST → 声明与具体类型表 → 常量/布局 → 按函数检查并生成有类型控制流 IR → RV64 汇编。

函数签名先登记，每个函数体只做一次正式类型检查与 IR 构造。位置检查产生 Place，值检查产生 Operand；已知目标类型只用于当前表达式及规则允许的子项，不产生未解类型变量、不反向修改兄弟表达式。调用、复制、转换和操作顺序在此阶段决定，后端不重新解释源语义。

不同时维护完整 HIR 和一套重新处理相同规则的 HIR 降低器。AST 保存源结构；IR 操作记录类型、声明身份、源码位置、投影和作用域。defer 体在注册点解析名字并检查一次，生成可在出口实例化的清理片段；出口只装配已决定的操作，不重新做语义检查。return/?/break/continue 共用 exit_scopes，panic 不进入它。局部/临时槽身份在片段复制时正确重映射，外部捕获保持原绑定。

| 模块职责 | 唯一承担的工作 |
| --- | --- |
| syntax | 词法、文法、源码位置和 AST |
| resolve/types | 声明、作用域、具体类型身份、签名及访问权限 |
| constants/layout | 第 7 节的有限依赖图、常量值、布局与静态数据/重定位 |
| check/IR | 已知类型检查、Place/Operand、浅层覆盖、求值顺序与统一清理 |
| rv64 | 普通/C 标量 ABI、帧布局、指令发射及机器事实 |
| driver | 文件输入、外部汇编/链接、报告和诊断 |
| extend | 同版本只读视图、最小注册/执行接口与结果状态 |

Extend 读取声明/类型/源位置、实际复制/取址/读写、调用、控制流、清理顺序及目标事实。它可以验证库声明的句柄协议、初始化和并发使用，但不能改变 Core 的值复制或执行行为；没有实际实现的分析必须报告未提供。旧 Ownership/Borrow 验证规则和旧 HIR/实例接口不承诺兼容，也不能仅识别新元数据就报告原有保证成立。

## 17. 从设计到实施的验收边界

本轮交付的是语义设计。下表是未来实现的必要验收，不代表测试已执行；应先用这些用例验证架构，再扩展完整用例矩阵。

| 用例组 | 必须区分的结果 |
| --- | --- |
| 具体类型 | 普通递归/前向调用通过；泛型、缺省绑定/结果类型、方法、自动解引用拒绝 |
| 已知类型检查 | `let n:u32 = 1 + 2;` 通过；无已知整数类型的裸字面量、比较的跨操作数补型拒绝 |
| 复制与存储 | 复制后原值仍在；无隐式 retain/release/零填充；读未初始化槽属执行合同违反，不能当作已静态证明 |
| 指针与切片 | const 写入、非 kernel 普通解引用、隐式空间/const 转换拒绝；显式操作与边界 panic 按规则执行 |
| 浅层匹配 | 标签遗漏/重复、载荷类型不符、嵌套模式拒绝；显式嵌套 match 通过 |
| 清理 | 各种正常出口只执行已注册动作且 LIFO；返回快照先于清理；条件注册和循环每轮行为正确；panic 不清理 |
| 常量与布局 | const 引用通过，static 值读取/常量地址比较拒绝；静态自取址通过；按值递归和常量—长度—布局环拒绝 |
| 顺序与整数 | 实参逐项快照、RHS 先于 LHS、短路、零长度重复构造、每整数位宽及 panic/包装运算边界 |
| ABI | C 标量/指针双向、超八参数与聚合通过指针；聚合按值 C ABI 拒绝；普通聚合快照/结果槽保持独立 |
| 内核 | 真正 SC 原子与强 CAS、IRQ-save 恢复顺序、MMIO 单次访问与设备栅栏、trap 保存/恢复和禁止调度边界 |
| 代表模块 | 在新编译器上实现页表操作、锁、MMIO、ctx+ops 与失败回滚；所有新支持代码单独计量，不假设隐藏库已存在 |
| Extend | 实际只读信息和结果状态可用；未实现的验证器、已删除模型的保证不得报告通过 |

规模按全部手写编译器统计，包括驱动、类型/IR 与 Extend；生成表、运行时、平台汇编、支持库、生成工具和测试另列，并给出交付总账。排版压行、移动目录或把必要算法转入库不算语义简化。数千行目标需要新实现试点证实，本文不承诺净缩减比例。
