# 成本与架构判断

本文的架构比较与cost.json保留2026-10-13基线。2026-10-14行为修复后的当前值见[维护成本](../../../docs/workflows/behavior-fixes-2026-10-14/I-cost.json)：Q生产11,018行、VT runtime290行、S0 runtime19行；分别较基线增加27、89、0行。新增工具与测试另列，不覆盖旧发布所引用的cost.json。

这里区分实现完成、自举通过和复杂度目标达成。原方案的 8,000 行是原型软预算；当前候选超过预算。不能以固定点或测试数量抵销这项偏差。

## 统计口径

`python3 tools/measure_next.py` 从实际文件统计物理行、源字节及非空非注释行，结果见 `cost.json`。Q 编译器包含词法、声明/语义、初始化、IR、RV64、有限汇编、ELF、输入/驱动和 Blocking，所有维护中的生产 VT 都计入。运行库、机器适配、系统样本、测试、宿主工具、冻结 P/B/Rust 以及生成的 Unicode 表分别列账。冻结运行支持、原测试/夹具、原验证工具及剩余元数据也分别列出，覆盖 seed.json 的全部 71 个输入；元数据含旧参考、清单、锁文件和历史日志，不混入生产实现。仓库其余未被本引导链依赖的旧 0.5 树不属于本交付账本。测试生成的程序由生成它们的手写工具计账，不能把手写工具当作零成本。

ELF 的可写段是静态预留量，不是实测峰值 RSS；最高单函数 frame 不是整个调用链的栈峰值。1 MiB 栈结论来自目标进程实际自编译，不由单帧数字推导。

## 得到的保证与仍承担的成本

- 闭合 Syntax/Instruction 让新增变体遗漏在编译时暴露，消除了任意 tag/载荷组合。代价是受限语言没有模式分组选项，许多合法拒绝分支仍须逐个写出。
- NameId/TypeId 防止名字与类型索引混传；NodeId、TypeSyntaxId、SlotId、LabelId 和参数范围还携带相应生命周期检查。unsafe 伪造内存不在这个保证内。
- 类型与声明条目一旦完成便不能覆盖；具体派生类型仍可追加。临时函数空间由驱动统一开启和释放，分析保留稳定摘要而不保存临时句柄。
- 调用式 defer 删除任意 CFG 的捕获/重放；保存实参和聚合快照仍是规定语义，不能为了省代码删去。
- InitData 隔开语法检查与数据序列化；这种分离增加一种具体记录，却避免后端重新绑定名字或解释源码。
- 直接 ELF、固定 RV64、逐函数 arena 和有限 S0 仍是复杂度边界。没有为迁移加入 HIR、SSA、visitor 框架、泛型容器、借用检查或第二个长期维护编译器。

## 读者检查改动的入口

新增一种源表达式，需要检查 parse 的 Syntax/构建、types 的受限常量与绑定、init 的静态接受规则、check 的运行语义。共享的名字/调用/字段解包查询只维护一份穷尽判断。源级 defer、match 和字段语义在检查阶段消失，不进入 RV64。

新增一条 IR 指令，需要在 ir 的具体载荷/构造/生命周期、rv64 的验证与发射、Blocking 的调用提取中明确其含义。后端帧和标签表属于后端；不能向语义 IR 写入机器偏移。新增影响调用的操作还必须改变分析保证，不能默认为不阻塞。

这套表示提高了内部错误的可检测性，但没有证明它在教学上已足够短。8,000 行目标未达是必须保留的结论。下一次语言取舍应先针对重复的闭合分派与具体使用场景做小试点；不能通过压行、把算法藏进生成器，或恢复长期双实现来宣称简化成功。

## 全局写入与跨阶段依赖

[ownership.md](ownership.md) 按实际表列出每个公开写入口、所有者和封口边界；`cost.json` 的 `state_inventory` 逐模块列出所有 mutable static，包括公开标量。当前共有 151 个 mutable static（B 为 130 个），其中 9 个公开：check 的 max_bindings/max_defers/max_loops、model 的 max_ast/max_ir/max_frame 与终端 error 字段仍为共享标量；它们不允许外部改写源码、语义条目或映像数组。

| 阶段 | 本阶段可变状态 | 对前阶段的依赖 |
| --- | --- | --- |
| 输入/声明 | input 私有字节与一次完成的头；parse 持久头节点；model 名称/声明追加 | 字节冻结后不再变化，扫描游标只属于 parser |
| 绑定/布局 | types 私有绑定/递归侧表；model 类型追加与一次完成 | 只读声明语法，递归诊断保存 Span；布局不重新扫描源码 |
| 静态初始化 | init 私有 InitData；image 对象范围内写入 | 只读完成类型/声明，序列化不回到语法 |
| 函数检查 | parse 函数 arena；check 绑定/清理/循环表；IR 构造 | 读取稳定语义条目，允许追加派生类型/字符串对象 |
| 验证/分析/发射 | rv64 帧/标签侧表；Blocking 稳定调用摘要；image 机器字节 | IR 封口后只读；发射票据单次消费；函数 arena 在消费完成后释放 |
| 链接/发布 | image 内部补丁与最终封口；main 文件发布 | 所有符号必须完成，封口后不能再改映像；输出失败清理仅限新建文件 |

这是单次编译、逐函数复用的有界全局存储架构，没有把它扩展成可重入或并发编译服务。跨阶段仍有共享只读表与受检追加，不能声称所有阶段都是纯函数。
