# N5 r1 集成候选

输入为独立通过的 N4 r1。本节点只添加复现脚本、证据与 README；N4 产品文件及其哈希保持不变。实施者为 /root，最终通过须由 /root/b31_review 独立判定。

- `clean_build.py` 仅复制声明源码与测试，从新目录重新构建 C0。离线锁定依赖完整 91 项通过，0 失败、0 忽略，逐标签核对旧 81 项全部保留。随后在测试框架之外执行三个仓库清单，空 PATH、1 MiB guest 栈，C2/C3 全文件一致。
- `migration.py` 校验保留的旧 B3 C2 哈希，隔离目录仅复制 manifest 输入。旧 B3→D1→D2→D3 三代 ELF 全等；D3 开启实际 `pure.blocking` 六个入口全部 Verified，产物与关闭分析的 D2 全等。三个 syscall trace 检查只读取声明输入/清单/政策及创建输出，没有 execve 或编译器自读。
- 两条独立启动路径最终得到同一 SHA-256 `0793011738def41baca6387a7a6917c690ddbe15ac812340b009866c8aa56ffc`，ELF 1,108,040 字节，RW 53,118,748 字节，映像跨度 54,023,964 字节，最大单函数 frame 26,384 字节。RW 与跨度均低于 64 MiB；这些不代表进程 RSS 或调用链栈峰值。
- 新源码扰动、编译器源码扰动、多代行为、on/off、Unknown/Violation 门禁由完整回归中的现有 B3 测试及新增测试实际运行；N4 的独立随机图 oracle、边界和语义写入变体证据保留，未重复声称为 N5 作者的独立验收。
- `metrics.py` 统计全部 13 个生产 VT 模块，共 269,906 字节、8,249 物理行、7,843 code 行；运行库 189 行和 s0 19 行另列。Blocking 的 354 行是目标编译器内的子集。Rust seed 7,681 行、生成 Unicode 2,096 行、旧 B2 试点、测试及工作流工具分别记账。N1 排版展开和命名改善不能作为语义规模下降的证据。
- README 更新当前命令，保留并标注历史 B2/B3 规模与证据。说明状态所有权、纯规则、IR 只读、静态完整验证、读取顺序、Blocking 边界以及 Linux-user 的自编译范围；没有声称完整 R1a 或 SOS 内自举。

完整日志、源文件哈希与统计分别在 N5-clean/、N5-migration/、metrics.json。忽略的 build/b31-final.elf 保存迁移验证后的可执行文件；从源码或旧 seed 均能复现。未改旧 B3 冻结记录。
