# Core S 设计合同

本轮交付一套足够小、内部一致、可据以修订参考手册的语义设计。产品实现仍是 reference 0.5；本轮不修改 src、运行时、平台或测试预期，不承诺未经试点的净行数。用户允许 Core 写法繁琐，优先减少规则和实现机制，仍要求内核表达能力与 Extend 接口。

## 已有决定

- Rust 实现，直接生成 RV64 汇编，完整交付包含平台运行支持及 QEMU 验收。
- 用户接受移除用户泛型和求解型类型推导的方向；固定内建类型构造与从已知类型计算表达式结果需要明确区分。
- defer 暂时保留；当前没有 RAII，不引入自动析构。
- 允许修订 Core。此次要求制定语义，新增破坏性取舍须在最终设计中明确说明，不冒充已实施或逐项得到用户确认。

## 本方案的共同边界

采用一个明确的候选，避免交付菜单式方案。候选暂名 Core S，保留现行 0.5 文档作为对照；新的源语义不得宣称兼容 rv64-core-v1 全部原有合同，平台命名和继承范围由 K 节点明确。

普通值采用统一值复制；不提供隐式移动、Copy/resource 分类、自动析构及语言引用类型。内存访问通过显式的带 const 和地址空间的原始指针及固定切片描述符表达。复制句柄不意味着复制其资源所有权；生命周期、释放次数与别名约束是明确的执行合同，Extend 可附加证明，不能改变 Core 的执行语义。必须在最终文档标出这一新增取舍的工程代价。

保留整数、bool、unit、仅结果位置的 never、指针、函数指针、定长数组、具名结构体和具体枚举；Option/Result 如保留只作为固定类型构造，不能调用用户泛型代码。局部绑定、参数和结果须写类型；已知位置中的字面量定型可以保留，禁止未知类型变量、统一、跨同级反推、默认结果修复。

移除 impl/方法语法及自动借用、自动解引用、右值接收者临时借用；用普通具名函数和显式取址/解引用。只保留简单控制流、显式返回及浅层匹配；排除递归模式矩阵。defer 和 Result 的 ? 必须有统一、明确的退出语义。不要因为这些决定就强行保留块值、带值 break、元组、for、复合赋值等旧便利；L 节点须作出一个具体选择。

常量使用受限表达式语言；长度必须具体，禁止泛型重放与通用编译期解释器。必须闭合结构体布局、具名常量、sizeof/alignof/offsetof 的依赖与初始化规则，不能用禁止循环的口号替代可实现的判定。

内核入口、布局、静态对象、C ABI、原始存储、原子、MMIO、CSR/汇编和 panic 必须有具体可表达路径。不要求保持旧的所有便利包装器、所有原子宽度和所有 FFI 按值类型；删减必须明确，能展示代表性内核操作的替代方案，不能藏进未定义的库、宏、宿主 C 或未来扩展。

Extend 保留源位置、类型/声明身份、明确内存操作、控制流和目标事实的只读访问；不实现分析器。删除的引用/移动模型不能在接口描述里继续假装存在或声称旧 Borrow/Ownership 保证自动沿用。

## DAG 和所有权

R 共同合同 → L 语言与值语义、K 内核与目标接口（并行）→ S 整合语义、架构和验收文档。

- R 作者 root；独立审查者单独派发。
- L 作者 language agent，只写 build/simplification/core-s/L/；按本合同给出闭合的语言规则、正反例和移除机制。不得修改 K 或产品文件。
- K 作者 kernel agent，只写 build/simplification/core-s/K/；以本合同为共同边界给出内存和平台接口、代表性内核示例及局限。不得修改 L 或产品文件。
- S 作者 root，依赖已验收 L/K。最终文件 docs/design/core-s-semantics.md，README 只添加设计入口。独立审查者不得参与 R/L/K/S 编写。

## 验收

R：符合用户最新目标；输入边界、角色、可观察要求明确；图无环、并行写入不冲突。

L：单一确定方案；类型与值规则、字面量、位置、调用、控制流、match、?、defer、常量/布局/静态依赖闭合；能解释条件释放和副作用顺序；标出新语义及删除的旧机制；无泛型/求解器/引用/隐式移动借道回归。

K：具体的原始存储、页表、锁/原子、MMIO、C 调用、trap 及错误清理表达路径；列出有限内建接口族的类型、unsafe 和求值规则；明确目标继承/修订，不把伪代码当已编译；不能把关键能力推给不存在的库或验证器。

S：所有依赖最新版本已独立通过；正文消除 L/K 冲突，给出明确继承与排除边界、紧凑架构和未来可观察验收用例；新增破坏性取舍显眼；0.5 保持原样；文档示例和链接核对通过。设计审查通过只代表文档闭合，不代表编译器已实现或代码量目标已达成。
