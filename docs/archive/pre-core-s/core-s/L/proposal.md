# Core S：L 语言与值语义候选 r2

本文件是本次方案，尚未修改编译器，也不是用户逐项确认的新合同。
规范输入为已独立通过的 R r1（SHA256 `d9c95d3d804f55a2bb46959d4f831f8bc0bfb218167e25511e144c68d06a32de`）。
现行 `docs/reference.md` 0.5 仅作对照；下列破坏性删减不声称兼容 0.5。
L 决定源语义及依赖规则；K 决定有限机器内建、具体布局数字、ABI 和平台。
作者 `/root/core_s_language`；冻结后提交独立审查，作者的检查不算节点验收。

## 1. 本次方案的闭合边界

- 所有普通值统一复制；无 Copy/resource 分类、隐式移动、语言引用、自动析构。
- 无用户泛型、约束求解、实例化、impl、方法、自动借用／解引用、闭包、宏和重载。
- 控制流只有语句；保留 `if`、`while`、`loop`、浅层 `match`、显式 `return`、`?` 和块式 `defer`。
- 删除元组、newtype、for／for move、范围值／范围下标、块值、带值 break、解构绑定、复合赋值。
- 保留固定 `Option<T>`、`Result<T,E>` 类型构造；它们不是可以调用用户泛型代码的入口。
- 没有 CTFE 函数、常量块、常量 if／match 或通用表达式解释器。
- 所有删除项均为本次方案取舍；0.5 的实现、测试及参考手册维持当前状态。

## 2. 声明、名字和类型

源文件仍为 UTF-8；沿用 0.5 的标识符、注释、整数和字符串词法，不引入新词法。
文件为可选 `module path;`、导入、顶层声明；编译输入显式列文件，同模块合并并允许前向引用。
保留 `import path;` 及显式名字列表导入，无通配／别名导入、重导出、目录隐式模块和局部声明。
保留 `pub` 和 0.5 模块可见性；类型／值／模块名字空间、同域重名拒绝、内域遮蔽规则不变。
类型别名 `type A = T;` 透明；`struct S { field: T, ... }` 具名字段，可为空，无字段简写。
`enum E { A, B(T), ... }` 至少一个变体，每变体最多一个载荷；无字段式变体、显式判别值。
只有顶层普通函数、常量、静态对象、外部声明及 K 的有限目标属性；未知／重复属性拒绝。
`fn f(x:T, ...) -> U { ... }` 的每个参数及结果必须明写类型，无缺省 unit 结果。
普通函数体、不可达语句及未被调用函数都做基础检查；普通递归调用合法，无实例化缓存。
`unsafe fn` 将调用标为 unsafe；其函数体仍需显式 `unsafe { ... }` 授权操作。
本次删除 `effects` 源语法；Extend 读取调用及目标事实，不能把源标记缺失当成不阻塞证明。

对象类型闭合集合：
`u8/u16/u32/u64/usize`、`i8/i16/i32/i64/isize`、`bool`、`()`、原始指针、函数指针、数组、切片、具名结构／枚举、固定 Option／Result。
`usize/isize` 宽度由 K 目标固定；无浮点、128 位整数、引用、元组或任意用户类型参数。
`!` 仅可写在函数／函数指针最外结果位置，不可作为载荷、参数、数组元素或指针目标。
`[N]T` 的 N 是类型为 `usize` 的受限常量；允许零长度，仍依赖 T 的合法有限布局。
`[]T`／`[]const T` 是 kernel 地址空间的固定描述符 `(data,len)`，无元素所有权与生命周期参数。
原始指针须明写空间：`*kernel T`、`*kernel const T`，同样可用 `user/phys/mmio`；无省略空间形式。
函数指针为 `unsafe? extern abi(C)? fn(T,...) -> U`，非空、不捕获环境；C 调用总须 unsafe。
具名普通函数在值位置产生其完整函数指针；特殊入口及内部操作不形成普通函数值。
函数指针相容要求参数、结果、ABI 和有效 unsafe 位相同；无安全到 unsafe 的隐式适配。
类型相等展开别名，比较名义声明身份、已求值数组长度及固定构造的全部实参。
无隐式整数提升、指针 const 弱化、数组转切片、结构转换或函数 ABI 转换。
指针／切片视图转换只走 K 明列的有限内建；整数 `as` 是本章唯一普通转换运算。

## 3. 字面量、构造及无需求解的检查

局部绑定只准 `let name:T = e;`、`var name:T = e;` 及 `var name:T;`，不准模式或省略类型。
`let` 不可重新赋值，`var` 可赋值；绑定从初始化完成后可见，`var name:T;` 从声明后可见。
`var name:T;` 是本次新增取舍：分配具体槽而不隐式填零；取址／写入可填槽，实际读取前必须有完整合法 T；Core 不做流敏感初始化证明。
读未初始化槽违反执行合同；没有 MaybeUninit／移动后状态，也没有通过 let 构造未初始化槽的语法。
丢弃表达式用 `e;`；不提供 `let _`，表达式丢弃不运行析构。

表达式检查只有 `check(e, 已知T)` 与 `synth(e)`，没有未知类型变量、统一或反复传播。
绑定初始化、赋值 RHS、return、已知调用形参、具名字段／载荷提供已知期待类型。
带后缀整数直接产生其整数类型；裸整数必须在已知整数期待位置，否则拒绝，不默认 i32。
一元负号加整数幅度可以表示有符号 MIN；其他字面量越界直接拒绝。
`true/false`、`()` 和字符串直接产生 bool、unit 和 `[]const u8`；字符串是静态 UTF-8 字节，不补 NUL。
`null` 只在已知原始指针期待位置合法；不能构造函数指针或切片空值。
`S { f:e, ... }` 明定 S，每字段恰写一次，按源码字段顺序求值，禁止隐藏或重复字段。
`E::V(e)` 明定枚举与变体，载荷由声明提供期待类型；无载荷用 `E::V`。
固定构造写 `Option::<T>::Some(e)`／`Option::<T>::None`、`Result::<T,E>::Ok(e)`／`Err(e)`，所有类型实参必写。
仅这两个构造和 K 单独列出的专用内部语法接受类型操作数；普通声明／调用无 `::<...>`。
数组 `[e,...]` 和 `[e;N]` 必须在已知 `[M]T` 位置，长度相等，元素按 T 检查；没有首元素反推。
重复构造求 e 一次再复制 N 份，N=0 仍求 e 一次；重复值不产生额外资源所有权。
无期待类型时，算术的两个操作数各自 synth 并要求同一整数类型；不以左／右兄弟反定型裸字面量。
有已知整数结果期待类型时，将该类型传给算术两侧；一元整数运算同理。
比较的 bool 结果不提供操作数整数类型，两侧各自 synth；因此 `if n == 0_u32` 合法，`if n == 0` 拒绝。
调用结果、字段、索引、? 结果由已知输入类型算出，再与期待类型比较；期待结果不能反改被调用者或输入。
`!` 调用表示该路径没有正常结果，允许用于任意已知结果位置；不是隐式对象类型转换。

## 4. 值、位置、访问及求值

初始化、读取、传参、return、赋值、构造及 match 都复制值；复制结构／数组复制全部逻辑成员，枚举仅有效标签与载荷。
复制语义不将填充或未激活载荷读成值，允许搬运其原始字节而不保证保持；复制指针／切片只复制描述符，不复制其指向对象。
覆盖和结束存储均不隐式释放；复制句柄不创建独立释放权，资源身份／别名／释放次数靠执行合同维持。
不得因可写原始指针或切片假设独占；两个别名依次访问同一合法 RAM 有确定顺序。
局部存储在所在块完成其 defer 后结束，参数存储在函数退出清理后结束；右值临时在所属完整语句结束时结束，无延长规则。
static 有程序生命周期；const 没有独立存储身份；字符串字节具有静态身份。

位置只包括局部／静态、kernel 原始解引用、位置的具名字段和数组／切片元素；无自动解引用。
`*p` 仅接受 kernel 原始指针，读取、写入和基于该原始位置取址都须 unsafe；其他空间走 K 内建。
字段无自动解引用；`p.field` 拒绝，`(*p).field` 合法；枚举载荷只能经 match／? 取得。
拥有聚合位置的字段／元素沿基位置可写性；const 指针和只读切片元素不可写。
`let s:[]T` 只冻结描述符绑定，元素仍可写；切片元素访问必须 unsafe，包含索引读、写及取址。
数组元素操作不要求 unsafe，除非基位置来源要求；索引只接受 usize，越界 panic，不能隐式转换有符号索引。
右值聚合可读字段／数组下标，但不可写或取址；求右值一次再复制选中成员，不延长临时。
数组伪字段只有 `.len:usize`；切片另有 `.data`，类型为与描述符相同 const 性的 kernel 指针；均只读。
数组位置 .len 不读元素，切片 .len/.data 读取描述符而不访问元素。
普通字段／下标读只读取选中成员，不预读整体；指针及切片描述符本身必须已初始化合法。
`addr_of(place)`／`addr_of_mut(place)` 不读取载荷或构造引用，后者要求可写位置。
其类型由位置确定为 `*kernel const T`／`*kernel T`；基址、索引各求一次，索引仍检查界限。
原始存储字段取址不要求字段已经初始化，但定位用的描述符和索引必须合法；不授予访问权或延长存储期。
static mut 的所有值访问／取址，及 extern static 的所有操作须 unsafe；普通 immutable static 只可 const 取址。
实际读写的存活、权限、对齐、表示、映射和同步合同由 K 明定；不满足时从该操作起超出规定语义。

调用先求 callee，再从左到右求参数；每项复制形成快照后才求下一项，最后进入函数。
聚合源码字段、数组元素、普通一元／二元操作数从左到右，各一次；`&&`／`||` bool 短路。
赋值只作语句 `place = rhs;`：先求并复制 RHS，再求 LHS 地址／索引，最后写入；不返回 unit 值。
RHS 的 ?／panic 提前退出则不求 LHS；LHS 定位失败不写入，已经发生的副作用不回滚。
原始位置赋值是类型化写入，可初始化未初始化目标，也可覆盖合法旧值，均不隐式释放。
整数保留 `+ - * / %`、包装 `+% -% *%`、`<< >> & | ^`、`~`、有符号 `-` 和整数 `as`。
普通算术溢出、除零、MIN 除／余 -1 及负号 MIN 均 panic；除法向零截断，余数与被除数同号。
包装按目标位宽截断；移位两侧同整数类型，计数不得负或达到位宽，否则 panic；左移丢高位，右移按符号扩展。
`as` 只接受整数到整数：数学值模目标 2^位宽，再以目标符号解释；无 checked_cast 或 `+? -? *?`。
`< <= > >=` 仅同类型整数；`== !=` 仅同类型整数、bool、unit、原始／函数指针，比较指针地址。
无聚合／切片相等、用户运算符、语言引用一元 &；逻辑 ! 仅 bool，不把整数当条件。
优先级沿 0.5：后缀、一元、as、乘除、加减、移位、位与／异或／或、序比较、相等、&&、||；二元左结合。
转换结果再用后缀须括号；删除范围／赋值表达式后不再需要块表达式后续 `* & -` 的特例。

## 5. 纯语句控制流与浅层 match

块只含语句，无尾表达式；普通表达式必须 `;`，块／if／match／while／loop／unsafe 块自身无需分号。
`if bool { ... } else { ... }`、`while bool { ... }`、`loop { ... }` 均是语句；条件每次按通常顺序求值。
`break;`／`continue;` 指向最近循环，循环外拒绝；无标签、带值 break、for 或 range。
`return e;` 必须写 e（包括 unit）；先形成完整返回快照，再清理退出作用域。
不用数据流求解返回类型：每函数签名已知，用语法树计算“可能到达块末尾”这一布尔量。
return 和 ! 调用无正常后继；顺序组合、if 两臂的或、穷尽 match 各臂的或；缺 else 保留正常后继。
while 总保留正常后继；loop 仅当语法中存在指向它的 break 才保留后继，包括不可达 break。
不按常量条件或 defer 是否必然 panic 优化这一判定；函数可能到达末尾则拒绝，unit 也需 return。
所有不可达代码仍检查名字／类型／unsafe／上下文，不提供新的正常路径。
K 的特殊上下文转移仅作末尾独立语句或 `return transfer(...);`，尾位置只沿最终嵌套块／if／match 臂传播，禁止循环／defer／其他表达式嵌套；先快照参数再清理。

`match e { pattern => { statements }, ... }` 先复制 e 一次，按源码顺序选择首个命中臂。
允许 bool 的 true／false、整数的同类型可表示字面量、枚举完整路径变体、最后 `_`。
载荷模式只能 `E::V(name:T)` 或 `E::V(_)`；T 必写并与声明载荷完全相同，绑定为 let，作用域为该臂。
固定 Option／Result 模式可写 `Some(name:T)`／`None`／`Ok(name:T)`／`Err(name:E)`，按被检固定类型识别。
无递归模式、载荷字面量、顶层绑定模式、结构体模式、范围／或模式、模式守卫或借用匹配。
整数必须有最后 `_`，即使逐列写全窄整数值；bool／枚举可覆盖全部顶层值，或用最后 `_`。
重复字面量／变体、多个 `_`、`_` 后续臂拒绝；覆盖就是 bool 两位或枚举变体位集，无递归矩阵。
嵌套判断须先绑定载荷，再在臂内写另一个 match；不允许跨臂共享 payload 绑定。

## 6. Result ? 与 defer 的统一退出

`e?` 仅对已知 `Result<T,E>`，当前函数结果必须为 `Result<U,E>`，E 精确相同，无隐式错误转换。
复制 e 一次；Ok 复制载荷成为 T；Err 复制 E 构成当前函数 Err 返回快照，执行正常退出清理。
`?` 在表达式任何合法操作数位置可用，错误立即停止其余操作数求值；const／static 初始化及 defer 内拒绝。
return／? 退出到函数，break／continue 退出到目标循环；所有退出共用作用域清理展开。
块自然结束也清理；continue 每轮退出循环体，下一轮重新建立存储及注册记录。

只保留 `defer { statements }`，删除 0.5 的 defer-call 形式（旧形式也在退出时求值，并非注册时快照）；执行到 defer 语句才注册当前块动作。
注册不求清理体中的表达式；动作在退出时按绑定当时值执行，只能引用注册点已经可见的名字。
一块内按注册逆序，内块先于外块；变量存活至该块所有动作结束，之后才结束存储。
defer 体允许普通表达式／赋值、带初始化局部、嵌套块、if、浅层 match 和 unsafe；不准循环或未初始化声明。
defer 体及其嵌套块不准 return、?、break、continue、defer 或目标上下文转移；被调用普通函数可自己正常 return。
条件注册位于所执行分支块，在该分支退出时执行；跨分支延后条件释放须在外块注册并使用显式 bool 状态。
return 快照先于清理，所以清理改动原局部不改变已复制返回值；Err 快照同理。
动作中 panic／不返回的普通调用停止该路径；panic 不展开、不执行剩余 defer，也不能捕获。
每次动态块内各注册点最多执行一次，循环体是每轮新块；编译器跟踪已激活注册点并在各结构化出口静态列出清理动作，无须运行时 flag 或可增长清理栈。

## 7. 常量、布局和静态初始化：有限依赖图

常量 AST 的白名单只有整数／bool／unit／字符串／null、const 名字、具名函数值、聚合构造、数组重复、整数运算／as、比较／逻辑。
常量比较仅允许同类型整数的序／相等比较及 bool／unit 相等比较；不准指针／函数地址比较，包括 null 或同一符号地址，重定位不须转为编译期数值。
另准 `sizeof(T)`、`alignof(T)`、`offsetof(S,field)` 和本单元已定义 static 的静态地址／字段／常量数组下标取址。
静态 mutable 对象只能用 `addr_of_mut`／`addr_of` 取址并须显式 unsafe；常量上下文仅准 `unsafe { addr_of_mut(static-place) }`／`unsafe { addr_of(static-place) }` 两种专用形式。
上述专用形式是常量取址节点，不接受其他语句／尾表达式；不得借此引入一般块解释。
const 名字允许取得已求出的常量值并连到 C 节点，不读取存储；禁止 static 值读取、聚合字段读取、常量下标读、原始解引用、普通调用、局部绑定、控制流、?、defer 或一般 unsafe 块。
`const A:u32 = 1; const B:u32 = A;` 合法且 B=1_u32；`static A:u32 = 1; const B:u32 = A;` 拒绝 static 值读取。
固定 Option／Result 构造合法；数值地址构造、ptr_const、原始切片构造及全部 K 机器内建不在常量白名单，须运行时执行。
`.len` 只准数组类型已知的数组位置或字符串字面量：它是静态长度查询，不读取容器／static 初始化值。
不准常量读取切片变量 .len 或任意表达式 .len；需要重复使用长度就定义显式 `const N:usize = ...;`。
`sizeof/alignof` 只接受对象类型；`offsetof` 只接受具名结构单个可见字段，不接受递归路径／枚举载荷。
`const NAME:T = C;` 及 `static mut? NAME:T = C;` 的 T 必写，C 按 T 检查，static 不准无初始化器。
`static_assert(C);` 仅模块级，C 必须为 true 的常量 bool；无函数内断言执行／解释。
白名单检查所有子树；常量运算用运行时位宽规则，失败变编译错误；&&／|| 只求需要的一侧。
依赖收集仍覆盖两侧及所有构造元素，包括零重复元素；不能以短路或零长度删除循环边。
常量 evaluator 只递归此白名单 AST，无执行帧、语句、用户调用、跳转或内存读取；总步骤受有限输入及数组输出大小约束。

先收集全部声明、透明展开别名；别名引用图遇到任何别名即加边，穿过指针也加边，别名环一律拒绝。
具名结构／枚举作为身份边界停止别名展开，故 `struct Node { p:*kernel Node }` 合法。
建立节点 `C(name)` 常量值、`N(每个数组长度出现)`、`A(每个 align 参数)`、`L(每个具体对象类型)`、`I(static)` 初始化。
建图时数组类型键使用长度出现 N 的身份，不先求长度；拓扑计算 N 后才规范化数组长度、完成类型相等检查。
数组长度／align 参数的类型均检查为 usize，所有类型出现中的 N 和 A 都成为根，不因位于指针目标／未用函数而跳过。
每个声明的对象布局、每个 C/I/assert，以及每个 sizeof/alignof/offsetof 查询也作为根，未使用声明同样检查。
依赖方向为“请求者 → 所需节点”：const 引用到 C，长度到 N，align 到 A，布局查询到 L，static 初始化到其 C／查询／构造依赖。
`L(数组)` 连 N 与元素 L；`L(结构/枚举/Option/Result)` 连所有按值字段／载荷 L 及其 A；零数组也连元素 L。
`L(指针/切片/函数指针)` 只连目标固定表示事实，不连目标／签名类型 L；目标类型内的 N/A 仍独立检查。
`L(具体具名类型)` 使用声明身份缓存；固定 Option／Result 使用完整实参缓存；遇到正在展开节点记回边，不继续无限展开。
字段静态地址连根对象 L 与该字段偏移；数组静态地址还连下标常量及数组长度，检查边界与地址计算溢出。
取 static 根地址只依赖符号及根对象 L/A，不连 I；禁止把 static 初始化值当常量，故两个 static 相互取址合法。
例如 `struct Link { next:*kernel const Link }` 与 `static X:Link = Link { next:addr_of(X) };` 是合法重定位自环，非值依赖环。
对上述有限图做 DFS 三色或 SCC，任何可达循环均拒绝；拓扑序计算值／长度／布局，再检查大小、对齐及对象初始化。
`const N:usize = sizeof(A); struct A { x:[N]u8 }` 的 C→L→N→C 必拒绝，不靠求值请求顺序或死分支侥幸接受。
`struct Bad { next:Bad }` 必拒绝；仅指针递归不构成 L 环；数组大小／偏移必须符合目标 usize 可表示范围。
布局机械计算由 K 固定，L 仅依此有限图请求一次，不允许布局调用用户函数或反向驱动表达式推导。
static 初始化只发数据与重定位，无执行代码、懒初始化或声明顺序；运行前所有初始化镜像建立，.bss 由 K 启动合同兑现。
external static 无 I 节点，只有 K 明定的对象／边界符号合同；不准用于常量静态取址规则。

## 8. 正反例与迁移代价

以下是语言设计例，不宣称当前编译器支持；`prepare`／`release` 为应用自己的具体普通函数签名，非隐藏泛型库。
```text
struct Ticket { id:u32 }
enum Failure { Bad }
// 已声明：fn prepare(t:Ticket) -> Result<(),Failure>；fn release(t:Ticket) -> ()。
fn finish(t:Ticket) -> Result<Ticket,Failure> {
    var pending:bool = true;
    defer { if pending { release(t); } }
    let done:() = prepare(t)?;
    pending = false;
    return Result::<Ticket,Failure>::Ok(t);
}
fn sum(a:u32, b:u32) -> u32 { return a + b; }
fn select(v:Option<u32>) -> u32 {
    match v { Some(x:u32) => { return x; }, None => { return 0; } }
}
```
finish 的 Err 路径先保存错误，再 release 一次；Ok 路径清理时 pending=false；panic 路径无清理保证。
若调用 release 之后又使用 t，Core 不以句柄复制语法拒绝，但实际使用已释放资源违反应用／底层操作合同。
`let n = 1;`、`if n == 0`、`fn f()->u32 { 1 }`、`loop { break 1; }` 全拒绝。
`match v { Some(0) => {}, None => {} }` 拒绝递归载荷模式；先 `Some(x:u32)` 再比较或嵌套 match。
`defer { prepare(t)?; }`、`const N:usize = f();`、`const N:usize = if true {1} else {2};` 全拒绝。
`const SAME:bool = addr_of(X) == addr_of(Y);` 拒绝地址常量比较；运行时同类型原始／函数指针比较仍合法。
`let p:*kernel u32 = addr_of(n);` 拒绝 const／mutable 类型不符；`addr_of(1_u32)` 拒绝非位置。
`var slot:Ticket; unsafe { /* K 的 write(addr_of_mut(slot),t) 可初始化具体槽 */ }` 不产生析构或隐藏分配。

移除整套机制：实例化与递归实例检查、类型变量统一／默认修复、Copy/resource 结构分类、移动状态、引用与再借用、方法接收者搜索、模式矩阵、块结果／循环结果合流、常量语句解释器。
保留算法：名字解析／别名无环、已知类型双向检查、有限对象布局、受限常量 DAG、位置读／写区分、标签位集覆盖、结构化可达性、显式退出清理和目标降低。
迁移需展开泛型为具体函数／类型，以普通函数及显式取址替代方法，以 while 替代 for，用具名结构代替元组，并重写常量控制流为有限标量公式／明确常量。
统一复制可能复制大聚合并产生句柄别名；改用原始指针传递可降低成本，但初始化、有效期、同步及单次释放责任更显式。
无语言借用／所有权保证；Extend 可读源位置、声明／类型身份、实际复制／地址／访问、控制流、defer 和目标事实，不得假装旧 Ownership/Borrow 保证自动保留。
