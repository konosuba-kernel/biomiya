# Core S Linux 运行支持

当前 VT 编译器与测试程序共同使用这些文件：

- `bytes.vt`：切片比较、子视图和路径检查；视图不分配，也不延长输入存储的寿命。
- `linux.vt`：argv、文件打开／关闭、短读写循环、EINTR 重试及有界整文件读取。一次 read 最多请求 4096 字节；close 不盲目重试，以免复用后的描述符被再次关闭。
- `linux.s0`：C ABI 参数传递、系统调用和启动适配。`_start` 保存初始 sp 到 x27，普通函数及汇编适配保持该寄存器。

Linux 适配使用 Linux v6.12 asm-generic 系统调用 ABI；负 errno 按 usize 原始位模式识别。运行库不包含编译器的扫描、清单、类型或代码生成逻辑。输入视图在 unsafe 访问期间必须保持有效；路径检查不是应对并发路径替换的安全沙箱。

早期扫描与复制程序已移入 [B2 输入处理回归夹具](../tests/fixtures/b2-input/README.md)，其容量和退出码只属于该试点，不是当前编译器的上限。`tests/b2_runtime.rs` 继续用真实 RV64 程序及短 I/O／错误注入验证运行库。
